# 塔尔科特·帕森斯

## Summary

塔尔科特·帕森斯（1902-1979）是美国著名社会学家，被公认为宏大理论的最突出代表。其主要著作《社会系统》被米尔斯作为批判宏大理论的典型案例。帕森斯的社会学理论以社会系统、价值取向模式和规范性结构等概念为核心，强调社会秩序如何通过共享价值和制度化得以维持。

## Key facts

- 帕森斯是宏大理论的最突出代表，《社会系统》是其著作中最为重要的作品. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p33]
- 帕森斯认为价值取向的概念是一种逻辑上的工具，用于阐述融入行动系统中的各种文化传统之关联的核心特征. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p33]
- 帕森斯将秩序问题集中于行动者的动机与规范的文化标准间的整合. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p34]
- 帕森斯认为当一个标准被制度化时，它既是满足行动者自己需要倾向的方式，也是优化其他有影响力行动者反应的条件. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p36]
- 帕森斯提出与完全制度化对立的一极是失范，它是指互动过程中缺乏结构化的互补性. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p37]
- 帕森斯认为只有通过内化制度化了的价值，才会在社会结构中产生行为动机的真正整合. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p39]
- 米尔斯转述帕森斯社会系统理论的主要答案是：被共同接受的价值使社会秩序成为可能. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p40]

## Inferences

- Inference: 帕森斯的社会学实际上涉及的主要是合法性的东西，而不是任何一种制度
- Inference: 帕森斯通过定义，把所有制度性结构转化为一种道德领域或符号领域

## Uncertainties

- Uncertain: 米尔斯指出帕森斯在战败后德国的案例中，使用了非常马克思主义的术语来分析经济和职业结构，这是否意味着帕森斯理论内在的矛盾
