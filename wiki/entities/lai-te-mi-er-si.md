# 赖特·米尔斯

## Summary

C.赖特·米尔斯（C. Wright Mills, 1916-1962）是20世纪中叶美国重要的社会学家和公共知识分子，曾任哥伦比亚大学社会学系主任。他以对社会权力的批判性分析和社会学想像力的倡导而闻名。代表作包括《社会学的想象力》（1959）、《权力精英》（1956）和《白领》（1951）。

## Key facts

- 米尔斯在本书中阐述了社会科学家的三种政治角色：哲学王、国王的幕僚、以及独立自主者。. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p201]
- 米尔斯强调社会科学家应当将个人困扰转换为公共论题，将公共论题转换为其对各种类型个体的人文意义。. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p211]
- 在附录中，米尔斯详细描述了自己的治学方法，包括学术档案的建立、研究设计、笔记方法等。. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p213]
- 米尔斯著有《白领阶级》. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p253]
- 《社会学的想象力》第六章引用了米尔斯关于“当前社会研究的两种研究风格”的论文. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p255]
