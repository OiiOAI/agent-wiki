# Old Man Balance Test

## Summary

The Old Man Balance Test is a balance assessment that gauges dynamic balance—specifically the ability to maintain balance while in motion. Along with the SOLEC Test, it forms the two-part balance assessment protocol in the Built to Move book.

## Key facts

- The Old Man Balance Test assesses dynamic balance, meaning whether a person can balance while in motion. [raw/books/health/Built_to_Move.epub#L2048-L2057]
- Both the Old Man Balance Test and SOLEC Test reveal information about foot function, as feet are intimately connected to balance. [raw/books/health/Built_to_Move.epub#L2048-L2057]
- The test is performed barefoot in a wide-open floor space, balancing on the right leg while picking up a shoe with the left hand. [raw/books/health/Built_to_Move.epub#L2100-L2140]
- The test has three scoring levels: no touches indicates good balance mastery, one to two touches is pretty good, and three or more touches indicates balance needs work. [raw/books/health/Built_to_Move.epub#L2160-L2175]
- The test can be taken daily because taking the test itself is a balance practice. [raw/books/health/Built_to_Move.epub#L2180-L2190]

## Inferences

- Inference: The test's simplicity and accessibility make it a practical daily self-assessment tool for monitoring balance changes over time.
