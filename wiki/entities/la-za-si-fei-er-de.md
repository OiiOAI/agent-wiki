# 拉扎斯菲尔德

## Summary

拉扎斯菲尔德是抽象经验主义学派中比较有阅历的代言人，米尔斯通过引用和批评其论述来揭示抽象经验主义的学术方案和行政计划。拉扎斯菲尔德将社会学界定为一个专门领域，认为社会学家的首要职能是将社会哲学转换为经验科学，成为其他社会科学的方法论学家和工具制造者。

## Key facts

- 拉扎斯菲尔德将社会学界定为一个专门领域，不是因为它专有的方法，而是因为它的方法论的特殊性. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p71]
- 拉扎斯菲尔德认为社会学家是连接社会哲学家、个体观察家、评论者与经验研究者及分析家小组的桥梁. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p71]
- 拉扎斯菲尔德认为社会学家的任务是收集和分析概念，在解释特定领域中发现的经验结论时这些概念很有用. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p75]
- 拉扎斯菲尔德提出从社会哲学到经验社会科学的转变通常由研究中的四个转向体现：关注重点转向具体人类行为、联系其他部分研究、偏重重复出现的情境、关注当代而非历史. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p73]

## Inferences

- Inference: 米尔斯批评拉扎斯菲尔德的方案实际上是科学制造者的行政计划，将社会学定位为各门社会科学的助产士，这反映了抽象经验主义与行政机构发展的密切关联
