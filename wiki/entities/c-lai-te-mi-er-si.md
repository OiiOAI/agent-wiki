# C. 赖特·米尔斯

## Summary

C. 赖特·米尔斯（C. Wright Mills, 1916-1962）是美国社会学家，《社会学的想象力》（1959）的作者。本章是米尔斯对抽象经验主义的系统批判，他分析了该研究风格的特征、哲学基础及其对社会科学发展的负面影响，倡导回归古典社会科学的使命，关注社会结构与历史语境。

## Key facts

- 米尔斯认为抽象经验主义和宏大理论都逃避了社会科学的使命. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p62]
- 米尔斯指出抽象经验主义的研究堆积琐屑的细节，却对使这些细节形成一定规范形式缺乏足够关注. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p67]
- 米尔斯认为精确不应当同经验的或真实的混淆起来，尽管这种情况很常见. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p84]
- 米尔斯主张社会科学的重要著作过去一直是，并且现在也是谨慎推敲的假设，并用详细的信息对关键之处加以说明. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p84]
