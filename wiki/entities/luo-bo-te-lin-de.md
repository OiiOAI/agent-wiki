# 罗伯特·林德

## Summary

罗伯特·林德是美国社会学家，米尔斯在《社会学的想象力》第五章中引用了他对《美国士兵》研究的评论。林德批评了社会科学被用于控制和操纵人们为非自愿目标服务的现象，认为这是自由民主政权无能的重要表征。

## Key facts

- 罗伯特·林德评论《美国士兵》时指出，这几册书描述了科学如何被用于以熟练技能来选拔和控制人们为并非出于其自愿的各种目标服务. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p131]
- 林德认为这是自由民主政权无能的重要表征，因为必须日益应用社会科学但非以直接方式应用. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p131]
- 林德指出社会性的外在目标左右了社会科学的应用，其应用的每一个进展都倾向于使它成为控制大众的工具. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p131]
