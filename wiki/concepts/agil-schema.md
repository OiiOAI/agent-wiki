# The AGIL Schema

## Summary

The AGIL schema is Talcott Parsons's framework for analyzing all action systems, consisting of four functional imperatives: Adaptation (A), Goal attainment (G), Integration (I), and Latency/L-pattern maintenance (L). Each function must be performed for a system to survive. The behavioral organism handles adaptation, the personality system performs goal-attainment, the social system handles integration, and the cultural system performs latency. At the societal level, the economy performs adaptation, the polity performs goal attainment, the fiduciary system (e.g., schools, family) handles latency, and the societal community (e.g., law) handles integration. Parsons designed the AGIL scheme to bring dynamism to structural analysis.
