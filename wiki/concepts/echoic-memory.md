# Echoic Memory

## Summary

Echoic memory is the auditory form of sensory memory, storing aural information briefly after the original sound has occurred. Unlike iconic memories, echoic memories can persist for up to three or four seconds.

## Key facts

- Echoic memory is the aural counterpart of iconic memory, holding auditory information. [raw/books/neuroscience/The forgetting machine _ memory, perception, and the - Rodrigo Quian Quiroga; hoopla digital.pdf#L5341-L5343]
- Echoic memories can last up to three or four seconds, longer than iconic memories which last only a fraction of a second. [raw/books/neuroscience/The forgetting machine _ memory, perception, and the - Rodrigo Quian Quiroga; hoopla digital.pdf#L5341-L5343]

## Inferences

- Inference: The longer duration of echoic memory compared to iconic memory may reflect differences in how auditory and visual information are processed, with auditory information requiring more time to integrate.
