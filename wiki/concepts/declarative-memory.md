# Declarative Memory

## Summary

Declarative memory is a type of long-term memory for events and facts that people can state openly what they learned. Henry Molaison lacked declarative memory after his operation, unable to remember new experiences or facts. The term distinguishes this memory system from nondeclarative memory, which is demonstrated through performance without conscious recollection. Declarative memory depends on the medial temporal lobe, particularly the hippocampus and surrounding cortex. The concept was established through studies of Henry and other amnesic patients.

## Inferences

- Inference: Henry's preserved abilities to learn motor skills and perform priming tasks without conscious recollection demonstrated that nondeclarative memory operates independently of declarative memory.
- Inference: The medial temporal-lobe structures removed from Henry's brain were dedicated to declarative memory formation.
