# 科学哲学

## Summary

本章批判了社会科学中“科学”概念的模糊性，指出社会科学对“科学经验主义”的接受往往是表面和暧昧的。米尔斯认为科学哲学家的方法论模式虽然具有感染力，但对实际社会科学研究的直接作用有限，其应用应是“一般性的”，旨在解放想象力而非限制研究问题。

## Key facts

- 人们对“科学”的欣然接受往往既是表面上的又是暧昧的. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p136]
- 方法论中的“应急方案”不大可能有助于社会科学的发展. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p138]
- 单纯的理论或方法都不能作为实际社会研究的一部分. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p138]
- 我们应该喊出的口号是：每个人都是他自己的方法论学家. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p140]
- 观念是含有经验材料的思想，相对于经验材料思想过于宽泛会陷入宏大理论陷阱，让材料吞没思想会步入抽象经验主义圈套. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p140]

## Inferences

- Inference: 米尔斯在此章中主张社会科学应超越自然科学哲学的框架，强调研究者应自主掌握方法论而非被其束缚。

## Uncertainties

- Uncertain: 米尔斯对科学哲学的态度较为复杂，既有批评也有肯定其“解放想象力”的潜在价值。
