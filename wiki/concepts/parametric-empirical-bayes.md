# Parametric Empirical Bayes (PEB)

## Summary

Parametric Empirical Bayes (PEB) enables group-level analysis in model-based data analysis by treating estimated parameters for each individual as if they were generated by a second-level model. This allows testing hypotheses about causes of parameter variations across subjects.

## Key facts

- PEB uses a general linear model that generates a parameter of interest, taking explanatory variables into account. [raw/books/neuroscience/Active Inference _ The Free Energy Principle in Mind, Brain, - Thomas Parr; Giovanni Pezzulo; Karl J Friston; MIT Press.pdf#p185]
- The design matrix X contains columns for alternative explanatory variables and rows indicating each participant. [raw/books/neuroscience/Active Inference _ The Free Energy Principle in Mind, Brain, - Thomas Parr; Giovanni Pezzulo; Karl J Friston; MIT Press.pdf#p185]
- PEB can be performed using Bayesian model reduction without multiple model inversions. [raw/books/neuroscience/Active Inference _ The Free Energy Principle in Mind, Brain, - Thomas Parr; Giovanni Pezzulo; Karl J Friston; MIT Press.pdf#p185]
