# Affective Zombies

## Summary

Affective zombies are hypothetical beings that behave as if conscious but lack subjective feelings. Solms uses this concept to argue that achieving functional criteria for consciousness does not demonstrate the presence of subjective experience, and that different operational criteria are needed for voluntary behaviour versus sentience.

## Key facts

- Solms raises the possibility that 'affective zombies' might exist who behave as if conscious but are not conscious. [raw/books/neuroscience/The Hidden Spring - Mark Solms.pdf#p260]
- If a self-evidencing system achieves survival in unpredicted environments, the question remains whether it used feeling to do so. [raw/books/neuroscience/The Hidden Spring - Mark Solms.pdf#p260]
- Affective zombies demonstrate that unlike intelligence, where behaviour can be indistinguishable, consciousness may not be detectable through behaviour alone. [raw/books/neuroscience/The Hidden Spring - Mark Solms.pdf#p261]

## Inferences

- Inference: The zombie problem underlies Solms' insistence on non-behavioural criteria for testing artificial consciousness, such as demonstrating that the system values feelings uncoupled from adaptive consequences.
