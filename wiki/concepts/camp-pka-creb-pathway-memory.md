# cAMP-PKA-CREB Pathway in Memory

## Summary

The cAMP-PKA-CREB signaling pathway is a conserved molecular cascade underlying long-term synaptic plasticity and memory formation. In Aplysia sensory neurons, serotonin activates G-protein-coupled receptors, increasing cAMP and PKA activity, which leads to phosphorylation of ion channels and transcriptional changes via CREB (cAMP response element-binding protein) for long-term memory storage.

## Key facts

- In Aplysia sensory neurons, serotonin binds to G-protein-coupled receptors that stimulate adenylyl cyclase, producing cAMP and activating PKA. [raw/books/neuroscience/Eric Kandel PRINCIPLES OF NEURAL SCIENCE Sixth Edition - Eric R Kandel; John Koester; Sarah Mack; Steven Siegelbaum.pdf#p1317]
- PKA phosphorylates K+ channels to broaden action potentials, enhancing Ca2+ influx and transmitter release, and also phosphorylates proteins involved in the release machinery. [raw/books/neuroscience/Eric Kandel PRINCIPLES OF NEURAL SCIENCE Sixth Edition - Eric R Kandel; John Koester; Sarah Mack; Steven Siegelbaum.pdf#p1318]
- Long-term memory storage requires transcription (via CREB) and protein synthesis, distinguishing it from short-term memory that requires only post-translational modifications. [raw/books/neuroscience/Eric Kandel PRINCIPLES OF NEURAL SCIENCE Sixth Edition - Eric R Kandel; John Koester; Sarah Mack; Steven Siegelbaum.pdf#p1304]
