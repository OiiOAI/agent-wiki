# Procedural and Explicit Memory

## Summary

Neuroscientists recognize two major memory systems: procedural (or implicit) memory, which functions unconsciously for automatic actions and emotional memories and develops early in infancy; and explicit (or declarative) memory, which consciously recollects specific facts and events and is supported by language. Early childhood traumas are stored as procedural memories even when no explicit memories exist.

## Key facts

- Procedural or implicit memory functions when we learn procedures or automatic actions, occurring outside focused attention without requiring words, and includes nonverbal interactions and emotional memories. [raw/books/neuroscience/The Brain That Changes Itself - Norman Doidge.pdf#p233]
- Kandel stated that during the first 2-3 years of life, when an infant's interaction with its mother is particularly important, the infant relies primarily on its procedural memory systems. [raw/books/neuroscience/The Brain That Changes Itself - Norman Doidge.pdf#p234]
- Explicit or declarative memory consciously recollects specific facts, events, and episodes, helps organize memories by time and place, and is supported by language. [raw/books/neuroscience/The Brain That Changes Itself - Norman Doidge.pdf#p234]
- People traumatized in their first three years can be expected to have few if any explicit memories of their traumas, but procedural/implicit memories exist and are evoked when situations similar to the trauma occur. [raw/books/neuroscience/The Brain That Changes Itself - Norman Doidge.pdf#p234]
- Procedural memories often come 'out of the blue' and are not classified by time, place, and context the way explicit memories are, and commonly get repeated in transference or in life. [raw/books/neuroscience/The Brain That Changes Itself - Norman Doidge.pdf#p234]
- Analysis helps patients put unconscious procedural memories and actions into words and context so they can understand them, and plastically retranscribes these procedural memories into conscious explicit memories. [raw/books/neuroscience/The Brain That Changes Itself - Norman Doidge.pdf#p235]
- H.M.'s case proved that the hippocampus turns short-term explicit memories into long-term explicit memories for people, places, and things. [raw/books/neuroscience/The Brain That Changes Itself - Norman Doidge.pdf#p235]
