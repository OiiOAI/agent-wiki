# 学院派系

## Summary

学院派系是米尔斯在第五章第二部分分析的重要现象，指的是学术界中以派系形式组织的学术群体。米尔斯分析了派系的功能、运作机制、对学术声誉分配的影响，以及其与学术创新的复杂关系。他特别批评了派系世界中的「学术政治家」角色，指出这些角色往往具有一流心智但却不从事实际研究。

## Key facts

- 学院派系的功能不但是协调竞争，而且规定竞争的条例并分配遵循这些条例的研究成果的报酬. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p123]
- 派系最重要的学术特征是其在评价人、批判研究工作时所持的原则. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p123]
- 完成派系内在任务的手段包括：给年轻人友好的建议、提供工作、推荐其升职、把著作送到令人仰慕的评论家手中、分配研究基金. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p123]
- 以往人们一般期望学者在学院的声望建立在著作、研究报告和专论的出版基础之上. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p124]
- 学院政治家借助其声誉获得展示能力的手段，这些手段必须与其个人能力区别开来. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p124]
- 存在几个相互竞争的派系时，规模小的、被认为不重要的派系会被占主导地位的派系希望给驱逐出去. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p125]
- 学术政治家往往具有一流的心智，但他们的角色使其不从事实际的研究. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p127]
- 这些政治家积攒的声望与其实际所做如此不成比例，他们提出的承诺如此宏大，以至往往被阻挠去从事研究. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p127]

## Inferences

- Inference: 米尔斯指出派系世界并非学院世界的全部，还存在独立的学者，他们不参加这个游戏、不愿靠宣传声望获利
- Inference: 米尔斯认为派系对声望、荣誉和学者职业的牢牢控制会受到学院外的读者群和公众的兴趣或赞许的扰乱
