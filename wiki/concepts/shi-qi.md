# 士气

## Summary

“士气”是工业人际关系学派的核心概念。从主观角度看，士气意味着工人愿意完成工作且心情不错；从客观角度看，士气意味着工作干得有效率。米尔斯区分了两种类型的士气：一种是被异化的工人服从于被规整了的期望的士气，另一种是未被异化的人能够参与工作决策的自我管理的士气。

## Key facts

- 从主观角度而言，士气意味着工人愿意完成手中的工作，完成时心情很不错. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p107]
- 从客观角度而言，士气意味着工作干得很有效率，在最短时间内用最少的钱以最小的困难完成. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p107]
- 在现代美国工厂，士气与工人快乐的服从有关，这种服从引起的结果是管理层认为的高效工作. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p107]
- 第二种类型的“士气”是为未被异化的人假想出来的形式，在大规模集体工作的客观条件下设计自我管理. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p108]
- 工业社会学理论问题在士气概念中达到学术和政治的顶峰，它已成为探讨异化和士气类型的核心问题. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p114]
