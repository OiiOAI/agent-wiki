# 社会结构

## Summary

社会结构是由不同身份所组成的体系，社会身份注意亲疏、嫌疑、同异和是非之辨。社会是一个身份的结构，而非个人的集合体。性和社会关系都需要保持稳定和持久，社会总是避免社会关系的改变。

## Key facts

- 社会结构是由不同身份所组成的，社会身份注意亲疏、嫌疑、同异和是非之辨. [raw/books/sociology/乡土中国.epub#L3442-L3443]
- 社会并不是个人的集合体，而是身份的结构. [raw/books/sociology/乡土中国.epub#L3456-L3457]
- 社会关系是行为的模式，是一种轨道，贵在能持久. [raw/books/sociology/乡土中国.epub#L3457-L3458]
- 社会总是不太鼓励社会关系的改变. [raw/books/sociology/乡土中国.epub#L3458-L3459]
- 造成人们跌入陷阱感觉的，是世界上各个社会的结构中出现的似乎非个人性的变化. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p9]
- 经典社会分析家问的第一个问题是：一定的社会作为整体，其结构是什么，它的基本组成成分是什么，这些成分又是如何相互联系的. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p12]
- 个人只有通过置身于所处的时代之中，才能理解他自己的经历并把握自身的命运. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p11]
- “社会结构”这一应用极广的概念，是指根据其履行功能而进行分类的制度的组合，这是社会科学家所使用过的最有包容性的研究单位. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p145]
- 社会科学家历来将绝大部分注意力放在政治和经济制度上，不过军事和亲属关系，宗教与教育制度同样也被大量研究. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p145]
- 社会结构通常是在政治国家下组织起来的. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p146]
- 民族国家是当前世界历史上主要的国家形式，同时在每个人生活中也是一个重要的事实. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p146]
- 社会学与人类学的传统主题，都是整个社会. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p148]

## Inferences

- Inference: 米尔斯认为，由于所处制度变得更庞杂、彼此联系更复杂，结构性的变化数目和类型不断增加，因此要想对社会结构的观念有清楚的意识并敏锐地运用它，就要能在大量不同的环境中捕捉它们彼此间的联系
- Inference: 米尔斯强调理解社会结构需要与历史现实的层次以及这一现实对个人的意义保持长期紧密的联系，社会的每一制度事实都由这些联系构成。
