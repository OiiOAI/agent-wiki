# Schemas

## Summary

Schemas are mental frameworks that allow the brain to process, organize, and interpret information with minimal effort. Similar to architectural blueprints, schemas can be reused repeatedly to efficiently form new memories. For example, an IKEA schema allows you to navigate any IKEA store without forming entirely new mental maps. The DMN stores schemas separately for different components of experience (people, things, places, situations), and the hippocampus uses these schemas to rapidly construct episodic memories. Schemas can lead to memory errors when we fill in blanks based on what typically happens rather than what actually happened.

## Key facts

- A schema is a mental framework that allows the brain to process, organize, and interpret a great deal of information with minimal effort. [raw/books/neuroscience/Why We Remember_ Unlocking Memory's Power - Charan Ranganath.pdf#p62]
- Schemas enable memory compression—instead of forming entirely new memories for every café visit, we integrate common features into a single blueprint. [raw/books/neuroscience/Why We Remember_ Unlocking Memory's Power - Charan Ranganath.pdf#p63]
- The method of loci (memory palace) exploits schemas by placing information within familiar layouts for later mental retrieval. [raw/books/neuroscience/Why We Remember_ Unlocking Memory's Power - Charan Ranganath.pdf#p63]
- Schema-based reconstruction can cause memory errors when typical elements fill in for what actually happened. [raw/books/neuroscience/Why We Remember_ Unlocking Memory's Power - Charan Ranganath.pdf#p77]

## Inferences

- Inference: The same schema system that allows efficient memory formation can cause distortions because schemas capture what typically happens, not what did happen in a specific instance.
