# 创造历史与命运

## Summary

米尔斯讨论人类创造历史的能力与命运的关系，指出在现代工业社会，创造历史的权力手段已高度集中和巨大化，这标志着人类不必再处于命运的掌握之中。然而，帮助人们创造历史的意识形态已在西方社会中式微。

## Key facts

- 命运并非一件普遍的事实，它只是历史上一定类型社会结构的体现。. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p205]
- 创造历史的新方式标志着人类不必再处于命运的掌握之中，人类现在可以创造历史。. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p206]
- 这一事实由于那些给人们以创造历史希望的意识形态已在西方社会中式微，并且正处于崩溃之中，而具有讽刺意味。. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p206]
