# 社会整合

## Summary

社会整合是米尔斯在批判宏大理论之后提出的替代性研究框架。米尔斯认为对社会秩序问题的有用研究主要是根据整合模式，而运用这些模式要与特定范畴的历史上的及当代的社会结构保持经验上的密切联系。他区分了对应整合（如托克维尔时期的美国）和协同整合（如纳粹德国）两种类型。

## Key facts

- 不存在什么能让我们理解社会结构的统一性的宏大理论和普遍性的体系，对于古老的秩序问题，其答案也并非只有一个. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p57]
- 可以用对应整合的模型来构想托克维尔时期的美国，在经济、宗教、婚姻、身份和军事等制度秩序中，独立竞争的人们的自由进取精神占居支配地位. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p55]
- 纳粹德国是通过协同整合起来的，在经济秩序高度集中化、政治秩序存在分割现象的基础上，通过极权主义政党国家使三个支配性秩序协同一致. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p55-56]
- 这些整合模式也可被构思为历史变迁的研究模型. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p57]
- 上个世纪的美国史展现出一种过渡，即从一个主要靠对应整合起来的社会结构，过渡到一个更大程度上以协同为条件的社会结构. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p57]

## Inferences

- Inference: 社会整合概念强调要从具体的制度性秩序（政治、亲属、军事、经济和宗教）出发来分析社会结构，而不是从抽象的价值取向来推导
- Inference: 历史学理论的一般性问题不可能从社会结构理论的一般性问题中抽离出来
