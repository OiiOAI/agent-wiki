# Organisational Invariance

## Summary

Organisational invariance, a principle articulated by David Chalmers, states that any two systems with the same fine-grained functional organisation will have qualitatively identical experiences. If the causal patterns of neural organisation were duplicated in another substrate (e.g., silicon), the same experiences would arise. Solms accepts this principle but argues it applies only to the specific type of information processing that generates feeling.

## Key facts

- Organisational invariance states that any two systems with the same functional organisation will have qualitatively identical experiences. [raw/books/neuroscience/The Hidden Spring - Mark Solms.pdf#p249]
- Solms accepts organisational invariance but argues that experience requires the specific functional organisation that generates feeling, not all information processing. [raw/books/neuroscience/The Hidden Spring - Mark Solms.pdf#p250]

## Inferences

- Inference: organisational invariance holds and feeling is the right kind of information processing, then it should in principle be possible to create a conscious machine.
