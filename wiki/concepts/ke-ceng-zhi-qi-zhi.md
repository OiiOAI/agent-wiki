# 科层制气质

## Summary

科层制气质是赖特·米尔斯在《社会学的想象力》第五章中提出的核心概念，指的是现代社会科学研究中呈现出的科层制特征和倾向。这种气质体现在：研究过程的高度标准化和合理化、集体性和系统性的人的研究、依赖大型组织的资金支持、以及研究技术专家的形成。米尔斯的核心论点是，这种科层制气质主要服务于社会的非民主领域——军事基地、公司、广告中介机构和政府行政部门，其政治含义与民主社会的自主性形成张力。

## Key facts

- 科层制气质的核心特征是将社会调查的每一步都标准化和合理化，使学术操作过程本身变得科层化. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p116]
- 抽象经验主义在商业部门（尤其是广告公司的沟通部门）、军事组织并逐渐在大学中得到实行，开始投合于科层组织的服务对象所持有的任何目的. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p117]
- 科层制气质渗透入文化、道德和学术生活领域. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p117]
- 从事抽象经验主义研究需要研究组织和大量资金，研究费用上涨导致劳动分工的总体控制. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p119]
- 大学将从专业伙伴的圈子转变为整套研究性的科层组织，包含详尽具体的劳动分工. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p119]
- 科层制气质的研究风格与社会结构的主导趋势和独特思想类型相一致. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p122]
- 如果社会科学包含科层式的研究，它会丧失其社会和政治自主性. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p122]
- 科层制气质主要应用并服务于非民主领域：军事基地、公司、广告中介机构和政府行政部门. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p131]

## Inferences

- Inference: 米尔斯认为科层制气质的发展是当代社会结构中功能合理性科层组织应用越来越广泛的表现
- Inference: 米尔斯指出这种气质倾向于使社会研究成为控制大众的工具，从而对民主构成威胁
