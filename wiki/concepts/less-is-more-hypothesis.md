# Less Is More Hypothesis

## Summary

Elissa Newport proposed that children's learning limitations—poor working memory, distractibility, inability to track details—paradoxically advantage language acquisition by forcing attention to global, systematic patterns rather than local associations. This is analogous to Elman's finding that neural networks trained with degraded memory could learn complex grammar.

## Key facts

- Children's poor memories, distractibility, and limited working memory prevent them from learning by brute-force association, forcing reliance on global patterns. [raw/books/neuroscience/The Symbolic Species - Terrence W. Deacon.pdf#p145]
- Elman's neural networks learned complex syntax only when early training used degraded memory (random disruption of recurrent inputs), forcing attention to global regularities. [raw/books/neuroscience/The Symbolic Species - Terrence W. Deacon.pdf#p144]
- Staged training (simple sentences first, then complex) allowed nets to learn recursive structures that failed with concurrent presentation. [raw/books/neuroscience/The Symbolic Species - Terrence W. Deacon.pdf#p143]
