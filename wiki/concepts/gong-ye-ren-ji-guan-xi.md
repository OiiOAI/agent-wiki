# 工业人际关系

## Summary

“工业人际关系”学派是新实用性的典型代表，其核心概念是“士气”。管理者用“聪明-愚笨”、“理性-非理性”等分界线描述工人，而工人则用“快乐-抑郁”、“高效-低效”等分界线自我描述。米尔斯批评人际关系专家们没有考察现代工业的权威结构，他们的建议实际上是为管理精英服务的合理化趋势。

## Key facts

- 人际关系学派的核心建议是：要让工人们快乐、高效、乐于合作，只需要让管理者们成为聪明、理性和博学的人. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p107]
- 人际关系专家们允许雇员“发泄怒气”，而不改变他们工作时所处的结构. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p108]
- 人际关系专家们发现“正式组织”中存在“非正式组织”，这些身份组合抵制权威，并保护工人免受权威的滥用. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p108]
- 人际关系专家们的努力是用于操纵的，目的是以巧妙方式朝向为管理精英服务的合理化趋势. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p108]
- 在现代美国工厂，士气与工人快乐的服从有关，这种服从引起管理层认为的高效工作. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p107]
