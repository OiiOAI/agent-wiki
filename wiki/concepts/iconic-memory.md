# Iconic Memory

## Summary

Iconic memory is the visual form of sensory memory, holding visual information for a very brief duration. Unlike echoic memories, which can last several seconds, iconic memories persist for only a fraction of a second.

## Key facts

- Iconic memory is the visual counterpart of sensory memory and represents the persistence of visual impressions after the original stimulus has ceased. [raw/books/neuroscience/The forgetting machine _ memory, perception, and the - Rodrigo Quian Quiroga; hoopla digital.pdf#L5341-L5343]
- Iconic memories last for a fraction of a second. [raw/books/neuroscience/The forgetting machine _ memory, perception, and the - Rodrigo Quian Quiroga; hoopla digital.pdf#L5341-L5343]

## Inferences

- Inference: The extremely brief duration of iconic memory (a fraction of a second) suggests it functions primarily for immediate visual processing rather than sustained perception.
