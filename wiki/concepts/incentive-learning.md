# Incentive Learning

## Summary

Incentive learning is a process by which the incentive or reward value of an outcome is altered by virtue of the motivational state of the animal when contact with that outcome occurs. This process allows changes in motivational state to influence instrumental responding, but only after consummatory contact with the outcome in the relevant motivational state.

## Key facts

- Shifts in motivational state alone are insufficient to alter instrumental responding; the incentive value of the outcome must first be altered through consummatory contact with the outcome within a particular motivational state. [raw/books/neuroscience/Decision Neuroscience _ An Integrative Perspective - Jean - Claude Dreher; Léon Tremblay; Institut de sciences.pdf#p77]
- In incentive learning, the sensory features of an outcome must become connected with a specific motivational structure sensitive to nutrient commodities, which is modulated by deprivation conditions. [raw/books/neuroscience/Decision Neuroscience _ An Integrative Perspective - Jean - Claude Dreher; Léon Tremblay; Institut de sciences.pdf#p78]
- Activation of the outcome representation and an emotional response in contiguity constitutes incentive learning, from which more abstract values can be extracted. [raw/books/neuroscience/Decision Neuroscience _ An Integrative Perspective - Jean - Claude Dreher; Léon Tremblay; Institut de sciences.pdf#p78]

## Inferences

- Inference: The basolateral amygdala encodes the alteration in incentive value during sensory-specific satiety, while the insular cortex retrieves that value prior to performance.
- Inference: The amygdala-insular cortex circuit forms a functional system for encoding and retrieving incentive value to influence goal-directed behavior.
