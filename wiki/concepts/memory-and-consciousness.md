# Memory and Consciousness

## Summary

Memory and consciousness are deeply interconnected. Explicit memories (semantic and episodic) require conscious retrieval into working memory to become experiences, existing in a preconscious state when not actively retrieved. Tulving distinguished noetic consciousness (awareness of factual knowledge) from autonoetic consciousness (awareness of personal experiences with self-reference), while implicit memories operate nonconsciously as a-noetic states.

## Key facts

- Semantic memory involves factual knowledge about the world without personal involvement; episodic memory involves personal experiences with what, where, and when information. [raw/books/neuroscience/Anxious - Joseph LeDoux.pdf#p259]
- Episodic memory involves mental time travel, allowing recollection of the past and predictions about the future. [raw/books/neuroscience/Anxious - Joseph LeDoux.pdf#p261]
- Explicit memories can be verbally reported; implicit memories do not require consciousness for storage or retrieval. [raw/books/neuroscience/Anxious - Joseph LeDoux.pdf#p267]
- Both semantic and episodic memory depend on the hippocampus and related areas of the medial temporal lobe. [raw/books/neuroscience/Anxious - Joseph LeDoux.pdf#p262]
- Memories stored via the medial temporal lobe system are in an inactive, preconscious state until retrieved into working memory. [raw/books/neuroscience/Anxious - Joseph LeDoux.pdf#p264]
- Semantic memory corresponds to noetic consciousness (knowing), while episodic memory corresponds to autonoetic consciousness (remembering). [raw/books/neuroscience/Anxious - Joseph LeDoux.pdf#p271]
- A-noetic states are triggered automatically and remain concealed from consciousness, occurring with implicit memories. [raw/books/neuroscience/Anxious - Joseph LeDoux.pdf#p273]
- Episodic memory builds upon semantic memory; episodic memories of personal experiences are what allow experiences to be remembered as part of one's autobiography. [raw/books/neuroscience/Anxious - Joseph LeDoux.pdf#p261]
- Autonoetic self-consciousness requires episodic memory and is much more complex than noetic or factual consciousness. [raw/books/neuroscience/Anxious - Joseph LeDoux.pdf#p272]
- Retrieval of long-term memory and transfer into working memory are necessary steps for converting a preconscious memory into a consciously experienced memory. [raw/books/neuroscience/Anxious - Joseph LeDoux.pdf#p265]

## Inferences

- Inference: The reciprocal connections between cortical memory storage sites and cortical consciousness networks enable inactive preconscious memories to be accessed and become active conscious memories.
- Inference: Semantic priming operates nonconsciously and represents a form of a-noetic memory that does not require working memory, showing that semantic knowledge can exist both noetically and a-noetically.

## Uncertainties

- Uncertain: Whether nonhuman animals have true episodic memory or merely 'episodic-like' memory remains unresolved due to measurement difficulties.
