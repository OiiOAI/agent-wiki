# 异化

## Summary

“异化”是米尔斯在讨论工业人际关系时引入的重要概念。在大规模等级制工作组织出现后，工人的自我管理和自主决策能力被削弱，工人成为被异化的存在。米尔斯区分了两种士气：被异化的工人的士气和未被异化的能自我管理的工人的士气。19世纪社会科学的一个宏伟主题就是人在现代资本主义中陷入无权境地的同时，在心理上变得叛逆又更加苛求。

## Key facts

- 自我管理的巧匠能参与有关他工作的决策，并且也乐于这么做，他们属于亚当·斯密-杰弗逊所说的未被异化的人. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p108]
- 大规模等级制工作组织的出现使想像这种未被异化的人的所有假设条件变得荒谬可笑. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p108]
- 人际关系专家们所设计的士气是被异化的人的士气，他们服从于被规整了的或传统的对士气的期望. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p108]
- 如果不改变权力结构，就不可能有集体性的巧干之道和自我指导. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p108]
- 19世纪社会科学的一个宏伟主题就是人在现代资本主义的结构变迁中陷入无权境地，同时在心理上变得叛逆又更加苛求. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p114]
