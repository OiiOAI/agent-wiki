# Tickler File

## Summary

The tickler file is a three-dimensional version of a calendar that allows physical reminders to be held and 'mailed' to oneself for receipt on designated future dates. It requires forty-three folders: thirty-one labeled by day (1-31) and twelve labeled by month.

## Key facts

- The tickler file is essentially a simple file-folder system that distributes physical reminders so they appear in one's in-tray on a designated future date. [raw/books/productivity/Getting Things Done_ The Art of Stress - Fre - Allen, David.pdf#p234]
- The physical tickler requires forty-three folders: thirty-one labeled with numbers 1 through 31, and twelve labeled with month names. [raw/books/productivity/Getting Things Done_ The Art of Stress - Fre - Allen, David.pdf#p235]
- The tickler file demands only a one-second-per-day new behavior to make it work. [raw/books/productivity/Getting Things Done_ The Art of Stress - Fre - Allen, David.pdf#p235]
- For the system to work, one must check and update it every day. [raw/books/productivity/Getting Things Done_ The Art of Stress - Fre - Allen, David.pdf#p237]

## Inferences

- Inference: The tickler file represents a unique executive function: deciding not to decide until a certain point in the future.
