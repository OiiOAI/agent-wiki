# Working Memory Capacity as SA Predictor

## Summary

Working memory has limited capacity that must be shared between current operations and temporary storage of intermediate results and freshly encoded data. It serves as the central bottleneck in information processing, and its capacity varies considerably across individuals. SA is expected to be limited by working memory capacity because SA involves comprehending dynamic, multifaceted task situations that require conscious processing and attention allocation.

## Inferences

- Inference: The strong correlation between working memory and SA supports Endsley's hypothesis that SA depends critically on the working memory system.
- Inference: The finding that g and working memory load on the same factor suggests that working memory demands may underlie general intelligence in complex task performance.
