# Long-Term Memory

## Summary

Long-term memory is a persistent form of memory lasting days to years that requires anatomical changes including the growth of new synaptic connections and new protein synthesis. Unlike short-term memory which involves functional changes, long-term memory involves structural modifications to the nervous system.

## Key facts

- Long-term memory requires the synthesis of new protein. [raw/books/neuroscience/In Search of Memory_ The Emergence of a Ne - Eric R. Kandel.pdf#p223]
- Flexner discovered that drugs inhibiting protein synthesis disrupt long-term memory if given during and shortly after learning, but do not disrupt short-term memory. [raw/books/neuroscience/In Search of Memory_ The Emergence of a Ne - Eric R. Kandel.pdf#p223]
- Long-term memory results from anatomical changes: neurons grow new terminals or retract existing ones. [raw/books/neuroscience/In Search of Memory_ The Emergence of a Ne - Eric R. Kandel.pdf#p226]
- The same synaptic connections altered in short-term habituation and sensitization are also altered in long-term versions. [raw/books/neuroscience/In Search of Memory_ The Emergence of a Ne - Eric R. Kandel.pdf#p224]
- Long-term memory persists for as long as the anatomical changes are maintained. [raw/books/neuroscience/In Search of Memory_ The Emergence of a Ne - Eric R. Kandel.pdf#p226]
- The CREB switch is the same in several species, indicating conservation of memory mechanisms through evolution. [raw/books/neuroscience/In Search of Memory_ The Emergence of a Ne - Eric R. Kandel.pdf#p278]
