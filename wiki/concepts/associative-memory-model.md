# Associative memory model

## Summary

A model proposed by Rodrigo Quian Quiroga explaining how associations between concepts are encoded in the hippocampus through partial overlap between neural networks. According to this model, if concepts tend to appear together, the networks encoding them will often activate simultaneously, generating connections through Hebbian plasticity, so that some neurons encoding one concept begin to respond to related concepts.

## Key facts

- Associations are encoded by the partial overlap between the networks that encode different concepts—if the overlap were total, concepts would fuse together and be impossible to differentiate. [raw/books/neuroscience/The forgetting machine _ memory, perception, and the - Rodrigo Quian Quiroga; hoopla digital.pdf#p139]
- Total or relatively large overlaps would instead be a mechanism for associating different stimuli with the same concept—for example, recognizing that different photographs of Luke Skywalker and his spelled-out name all correspond to the same person. [raw/books/neuroscience/The forgetting machine _ memory, perception, and the - Rodrigo Quian Quiroga; hoopla digital.pdf#p139]
- According to Hebb's principle, 'neurons that fire together wire together,' which explains how associations can be generated quickly through neural plasticity. [raw/books/neuroscience/The forgetting machine _ memory, perception, and the - Rodrigo Quian Quiroga; hoopla digital.pdf#p139]

## Inferences

- Inference: This model explains both how different stimuli can be associated with the same concept (total overlap) and how associations between distinct concepts are created (partial overlap). The speed of neural plasticity explains why episodic memories can form from events experienced only once.

## Uncertainties

- Uncertain: The author notes these are personal and relatively recent ideas, far from being universally accepted.
