# Implicit Memory

## Summary

Implicit (or procedural) memory underlies habituation, sensitization, classical conditioning, and motor skills like riding a bicycle. Unlike explicit memory, implicit memory is unconscious and recalled directly through performance without awareness. It is stored in brain systems including the amygdala (emotional associations), striatum (motor habits), and cerebellum (motor skills). Milner's studies showed that H.M. retained implicit memory despite losing explicit memory function.

## Key facts

- Implicit memory underlies habituation, sensitization, classical conditioning, and perceptual and motor skills such as riding a bicycle. [raw/books/neuroscience/In Search of Memory_ The Emergence of a Ne - Eric R. Kandel.pdf#p143]
- Implicit memory is recalled directly through performance without conscious effort or awareness that memory is being used. [raw/books/neuroscience/In Search of Memory_ The Emergence of a Ne - Eric R. Kandel.pdf#p144]
- Implicit memory involves several brain systems: the amygdala for emotional associations, the striatum for motor habits, and the cerebellum for motor skills. [raw/books/neuroscience/In Search of Memory_ The Emergence of a Ne - Eric R. Kandel.pdf#p144]
- H.M. could learn the mirror-tracing task through implicit memory but had no conscious memory of learning it. [raw/books/neuroscience/In Search of Memory_ The Emergence of a Ne - Eric R. Kandel.pdf#p142]
- Implicit memory storage in invertebrates has been conserved over millions of years of evolutionary time in the mechanisms by which explicit memory is stored in vertebrates. [raw/books/neuroscience/In Search of Memory_ The Emergence of a Ne - Eric R. Kandel.pdf#p304]
- Several key molecular mechanisms of memory are shared by all animals despite behavioral differences between implicit and explicit memory. [raw/books/neuroscience/In Search of Memory_ The Emergence of a Ne - Eric R. Kandel.pdf#p304]
- In implicit memory storage, the attentional signal is recruited involuntarily (reflexively), from the bottom up: sensory neurons activated by a shock act directly on cells that release serotonin. [raw/books/neuroscience/In Search of Memory_ The Emergence of a Ne - Eric R. Kandel.pdf#p324]
- Serotonin triggers protein kinase A in Aplysia, and dopamine triggers protein kinase A in the mouse, but these signals of salience are called up in fundamentally different ways for implicit versus explicit memory. [raw/books/neuroscience/In Search of Memory_ The Emergence of a Ne - Eric R. Kandel.pdf#p324]
- Implicit memory is typically manifested automatically with little conscious processing, and includes priming, skill learning, habit memory, and conditioning. [raw/books/neuroscience/Principles of Neural Science, Fifth Edition (Principles of - Eric R_ Kandel; James H_ Schwartz; Thomas M_ Jessell; Steven.pdf#p1453]
- Implicit memory is preserved in amnesic patients like H.M., indicating it does not depend on medial temporal lobe structures. [raw/books/neuroscience/Principles of Neural Science, Fifth Edition (Principles of - Eric R_ Kandel; James H_ Schwartz; Thomas M_ Jessell; Steven.pdf#p1453]
- Patient H.M. learned to trace star outlines while viewing his hand in a mirror and improved with practice despite having no conscious memory of performing the task. [raw/books/neuroscience/Principles of Neural Science, Fifth Edition (Principles of - Eric R_ Kandel; James H_ Schwartz; Thomas M_ Jessell; Steven.pdf#p1453]
- Visual priming is correlated with decreased activity in higher-order visual (extrastriate) areas of cortex. [raw/books/neuroscience/Principles of Neural Science, Fifth Edition (Principles of - Eric R_ Kandel; James H_ Schwartz; Thomas M_ Jessell; Steven.pdf#p1453]
- Implicit memory is tightly connected to the original conditions under which learning occurred, unlike the flexible explicit memory. [raw/books/neuroscience/Principles of Neural Science, Fifth Edition (Principles of - Eric R_ Kandel; James H_ Schwartz; Thomas M_ Jessell; Steven.pdf#p1453]
- Implicit memory includes perceptual and conceptual priming, motor and perceptual skill learning, habit learning (probabilistic classification), and nonassociative learning (habituation and sensitization). [raw/books/neuroscience/Principles of Neural Science, Fifth Edition (Principles of - Eric R_ Kandel; James H_ Schwartz; Thomas M_ Jessell; Steven.pdf#p1505]
- Implicit memory is expressed without conscious awareness and tends to be inflexible, whereas explicit memory is consciously recalled with awareness of the act of remembering. [raw/books/neuroscience/Principles of Neural Science, Fifth Edition (Principles of - Eric R_ Kandel; James H_ Schwartz; Thomas M_ Jessell; Steven.pdf#p1459]
- Patients with medial temporal lobe lesions (amnesic patients) can learn mirror-reversed text normally, indicating preserved implicit memory, but patients with cerebellar lesions have impaired motor skill learning despite normal implicit perceptual learning. [raw/books/neuroscience/Principles of Neural Science, Fifth Edition (Principles of - Eric R_ Kandel; James H_ Schwartz; Thomas M_ Jessell; Steven.pdf#p1505]

## Inferences

- Inference: mplicit memory is not a single system but a collection of processes, and in simple invertebrates it can be stored within the reflex pathways themselves.
- Inference: The text suggests damage to unimodal sensory regions impairs modality-specific priming, indicating different neural substrates for different types of implicit memory based on sensory modality.
