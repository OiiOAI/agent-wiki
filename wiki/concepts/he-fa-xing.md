# 合法性

## Summary

合法性是米尔斯讨论帕森斯理论时涉及的重要概念。米尔斯指出帕森斯所谓的价值取向和规范性结构主要与合法性的支配符号有关，但这些符号并没有形成社会中的某个独立王国，它们的社会相关性在于人们运用它们来证明或反对某种权力安排。

## Key facts

- 通过把权威与为人们广泛信仰的道德符号、神圣象征和法律准则相联系，掌握权威的人尽力证明他们对制度统治的正当性. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p45]
- 支配符号在不同思想家那里有不同名称：莫斯卡的"政治手段"、洛克的"主权原则"、索雷尔的"统治神话"、韦伯的"合法性"、涂尔干的"集体表象"、马克思的"占统治地位的观念"、拉斯维尔的"权威符号"等. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p45]
- 帕森斯和其他宏大理论家称为"价值取向"和"规范性结构"的东西主要与合法性的支配符号有关. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p46]
- 我们不能仅仅假设必须有某套这样的价值或合法性占居主流，以防止社会结构解体. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p47]
- 如爱默生所说，"政府"并不一定"来源于人们的道德认同"，而要是相信政府确实来源于道德认同，则是把它的合法性和产生它的原因相混淆. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p47]

## Inferences

- Inference: 帕森斯之所以错误地构想了价值取向的规范性结构，部分原因可能是美国政治系统在历史中只有一次受到内部暴乱的威胁，这种延续性非常罕见
