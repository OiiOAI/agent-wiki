# 经典社会科学

## Summary

米尔斯提出并论述了“经典社会科学”的概念，认为大多数经典研究介于抽象经验主义和宏大理论之间，包含了面对社会与历史结构的抽象。这些研究重视经验，与日常意义和体验的世界贴得更近。经典社会科学既不是从微观研究中“逐步建设”，也不是从概念阐释中“演绎而出”，而是努力使建设和演绎同步。

## Key facts

- 大多数经典研究介于抽象经验主义和宏大理论之间，这些研究也包含了对所观察的日常环境的抽象，但这种抽象的方向是面对社会与历史结构的. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p141]
- 经典研究跟抽象经验主义一样重视经验，事实上它往往更重经验，与日常意义和体验的世界贴得更近. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p141]
- 在经典实践中，证明什么通常被认为与如何证明一样重要，甚至可能比之更重要. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p142]
- 经典社会科学既不是从微观研究中“逐步建设”，也不是从概念阐释中“演绎而出”. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p145]
- 经典社会科学的研究者们努力使建设和演绎同步，其方式是反复充分地阐述问题及其完整解答. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p145]

## Inferences

- Inference: 米尔斯认为经典社会科学传统是有成果思想的真正来源，抽象经验主义和宏大理论都靠这一传统过活，是“寄生虫”。
