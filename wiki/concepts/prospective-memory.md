# Prospective Memory

## Summary

Prospective memory is the ability to remember to carry out intended actions in the future. It is distinguished from retrospective memory (remembering the past) and is particularly vulnerable to absent-minded errors that reflect on a person's perceived reliability and character.

## Key facts

- Prospective memory involves remembering to do things in the future, such as remembering appointments, errands, and intended communications. [raw/books/neuroscience/The Seven Sins of Memory - Daniel L. Schacter.pdf#p75]
- Event-based prospective memory requires understanding why cue events do or do not trigger recall of intended actions. [raw/books/neuroscience/The Seven Sins of Memory - Daniel L. Schacter.pdf#p76]
- Time-based prospective memory requires understanding how we generate cues that will help us remember at a later time. [raw/books/neuroscience/The Seven Sins of Memory - Daniel L. Schacter.pdf#p76]
- Best prospective memory triggers are highly distinctive cues with few other associations in long-term memory. [raw/books/neuroscience/The Seven Sins of Memory - Daniel L. Schacter.pdf#p77]
- Prospective cues frequently fail when people are preoccupied with attention-consuming matters. [raw/books/neuroscience/The Seven Sins of Memory - Daniel L. Schacter.pdf#p79]
- Between one-third and one-half of elderly adults do not adhere to medication schedules due to time-based prospective memory failures. [raw/books/neuroscience/The Seven Sins of Memory - Daniel L. Schacter.pdf#p80]
