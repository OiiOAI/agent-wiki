# 预测与控制

## Summary

「预测与控制」是社会科学生涯中最常用的口号之一，也是技术治国论哲学家的核心主张。米尔斯批判性地分析了这一口号，指出其隐含着关于权力、理性和历史的混乱观念。他认为，接受这一口号意味着接受科层制的视角，而在这个视角下，可行的道德选择会大大减少。

## Key facts

- 「社会科学的目标是预测与控制人类行为」是社会科学生涯中最常用的口号之一. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p130]
- 预测与控制的口号以「控制自然」和「控制社会」之间不容辩驳的类比为基础. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p130]
- 这种表述暴露了唯理主义者空洞的乐观主义，来源于对理性在人类事务中可能扮演的角色、权力的本质、与知识间的关系的盲然不知. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p130]
- 要想像许多人一样自如地谈论预测和控制，就必须接受官僚们的观点，即世界是个可以被操纵的客体对象. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p130]
- 罗伯特·林德评论《美国士兵》时指出：这几册书描述了科学如何被用于以熟练技能来选拔和控制人们为并非出于其自愿的各种目标服务. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p131]
- 说社会科学真正的终极目标是「预测」，其实是用专家治国论的口号来代替本应合乎情理的道德选择. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p134]
- 接受预测作为终极目标等于接受了科层制的视角，据此视角可可行的道德选择会少许多. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p134]

## Inferences

- Inference: 米尔斯认为民主意味着对历史本身的结构性运行机制进行集体性的自我控制，而非科层制的单向控制
- Inference: 米尔斯指出如果不面对科层制发展所引发的问题来讨论预测和控制，就是放弃了一个学者应具备的政治和道德的自主性
