# 自由主义实用性

## Summary

自由主义实用性是美国社会学和政治科学中占主导地位的研究风格，其特征是对分散的情境问题的经验性研究，以及对多元主义因果关系的信仰。该思想认为社会事件的起因必然是大量、分散而微小的，因此主张谨慎的、渐进式的改革。米尔斯批评这种实用性具有抽象水平低、无法思考社会结构问题的缺陷，且往往将判断伪装为有时间先后的叙述，服务于中产阶级和小城镇的价值规范。

## Key facts

- 自由主义实用性是美国社会科学的主要政治和学术尺度，几乎所有公共修辞和意识形态都来源于此. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p99]
- 自由主义实用性的信徒倾向于根据“反社会”或“腐败”来表述政治事务的“病态特征”. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p102]
- 自由主义实用性是一种道德化的情境社会学，与控制个人问题的权威人士非常投合. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p102]
- 自由主义实用性包含“多元主义因果律”的思想，即社会事件由不可计数的因素促成. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p99]
- 理想化的“被调适的人”是社会化的人，他会为他人着想并友善地帮助他们，踊跃参加社区活动. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p105]
