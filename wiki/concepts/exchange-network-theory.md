# Exchange Network Theory

## Summary

Exchange network theory, building on Emerson's work, studies how dyadic exchange relations connect to form larger network structures. An exchange network is defined as 'a specific social structure formed by two or more connected exchange relations between actors.' Key components include a set of actors, distributed valued resources, exchange opportunities, actual exchange relations, and their interconnection in a single network structure. Connections between exchanges can be positive, negative, or mixed. The theory links micro-level dyadic exchange to macro-level phenomena through the structure of the network.

## Key facts

- An exchange network has the following components: (1) a set of either individual or collective actors; (2) valued resources distributed among the actors; (3) a set of exchange opportunities among all actors in the network; (4) some exchange opportunities developed into actually used exchange relations; (5) exchange relations connected to one another in a single network structure. [raw/books/sociology/现代社会学理论 - 第7版 - 美 - 乔治 - 瑞泽尔 - 后浪大学堂 - 2018.pdf#p327]
- Cook et al. define an 'exchange network' as 'a specific social structure formed by two or more connected exchange relations between actors.'. [raw/books/sociology/现代社会学理论 - 第7版 - 美 - 乔治 - 瑞泽尔 - 后浪大学堂 - 2018.pdf#p327]
- The idea of an exchange network links exchange between two actors (dyadic exchange) to more macro-level phenomena. [raw/books/sociology/现代社会学理论 - 第7版 - 美 - 乔治 - 瑞泽尔 - 后浪大学堂 - 2018.pdf#p327]
- Connections are positive when exchange in one relation positively affects exchange in another; negative when one inhibits the other; or mixed. [raw/books/sociology/现代社会学理论 - 第7版 - 美 - 乔治 - 瑞泽尔 - 后浪大学堂 - 2018.pdf#p327]
- Emerson stated: 'The purpose of this essay is to begin construction of a theory of social exchange in which social structure is taken as the dependent variable.'. [raw/books/sociology/现代社会学理论 - 第7版 - 美 - 乔治 - 瑞泽尔 - 后浪大学堂 - 2018.pdf#p327]
- Emerson concluded that social exchange theory was limited by its focus on two-person or dyadic exchange relations, and by treating those relations as interconnected, moved toward seeing exchange as embedded in larger network structures. [raw/books/sociology/现代社会学理论 - 第7版 - 美 - 乔治 - 瑞泽尔 - 后浪大学堂 - 2018.pdf#p334]

## Inferences

- Inference: Emerson's research demonstrated that social structure can be both a dependent variable (determined by exchange relations) and an independent variable (determining exchange relations), indicating a bidirectional relationship.
