# 治学之道

## Summary

米尔斯在附录中系统阐述了治学方法，包括建立学术档案、做笔记的技巧、交叉分类方法、研究设计、以及写作风格。他强调社会学的想象力体现为从一个视角转换到另一个视角的能力，并指出清晰写作的重要性。

## Key facts

- 治学之道要求在学术工作中融入个人的生活体验，持续不断地审视和解释个人体验。学术档案是把握体验的重要方式。. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p213]
- 社会学的想像力相当程度上体现为从一个视角转换到另一个视角的能力，这种想像力使得社会科学家不再局限于单纯的技术专家。. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p231]
- 交叉分类的技巧是构想并掌握新类型以及批判和修正旧类型的最好方法，如同社会学想像力的语法。. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p233]
- 写作的技巧就是要使得读者的语义圈与作者完全相一致，使读者站在同样的受控意义圈内。. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p239]
