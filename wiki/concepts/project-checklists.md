# Project Checklists

## Summary

Project Checklists are systematic processes for starting and completing projects consistently. The Project Kickoff Checklist ensures projects start by capturing current thinking, reviewing relevant folders, searching for related terms, moving relevant notes to project folders, and creating an outline. The Project Completion Checklist ensures material is reviewed for reusable Intermediate Packets before archiving.

## Key facts

- The Project Kickoff Checklist consists of five steps: capture current thinking, review folders, search for related terms, move relevant notes, and create an outline. [raw/books/productivity/Building a Second Brain - Tiago Forte.pdf#p177]
- The Project Completion Checklist involves marking the project complete, reviewing Intermediate Packets for reuse, and archiving. [raw/books/productivity/Building a Second Brain - Tiago Forte.pdf#p181]
- Pilots run through preflight checklists before takeoff to ensure all necessary steps are completed. [raw/books/productivity/Building a Second Brain - Tiago Forte.pdf#p177]
