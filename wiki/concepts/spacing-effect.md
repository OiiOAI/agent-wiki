# Spacing Effect

## Summary

The spacing effect is the finding that breaking study time into shorter sessions separated by gaps leads to better long-term retention than spending the same total time cramming. This occurs because memory updating during spaced sessions helps memories become less tied to specific contexts and easier to access in any situation.

## Key facts

- Spacing out learning sessions produces much better retention than spending the same amount of time cramming, due to the memory updating that occurs when retrieving information in different contexts. [raw/books/neuroscience/Why We Remember_ Unlocking Memory's Power - Charan Ranganath.pdf#p175]
- When reading material in different contexts, the hippocampus can pull up memories but struggles slightly because of the new context, causing cell assemblies to reorganize and place more emphasis on the core information. [raw/books/neuroscience/Why We Remember_ Unlocking Memory's Power - Charan Ranganath.pdf#p175]
- With repeated spaced study, memories lose distinctive contextual features and become easier to access regardless of location or mental state. [raw/books/neuroscience/Why We Remember_ Unlocking Memory's Power - Charan Ranganath.pdf#p175]
- Memory updating during spaced retrieval causes memories to lose idiosyncratic moment-specific details while becoming more generally accessible. [raw/books/neuroscience/Why We Remember_ Unlocking Memory's Power - Charan Ranganath.pdf#p175]
