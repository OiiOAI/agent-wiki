# 文化滞后

## Summary

“文化滞后”观点认为，随着技术不断进步，人们需要做出一定改变以“与技术相适应”。米尔斯批评这一概念常常被用来掩盖评价，将判断伪装为有时间先后的叙述，且不经常考察导致各地区变化率不同的利益团体和决策者。与此相对，凡勃伦的“滞后、超越和冲突”概念则引导对社会结构进行更深入的分析。

## Key facts

- “文化滞后”观点表明，随着技术不断进步，人们需要做出一定改变以“与技术相适应”. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p103]
- 许多社会科学家运用“文化滞后”时，将其政治意义滤掉，使它丧失了具体的结构性的寄托点. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p103]
- 凡勃伦的用语“滞后、超越和冲突”引导他对“工业相对于商业”进行了结构分析. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p103]
- 凡勃伦力图揭示那些因循企业标准的商人训练出的无能如何导致对生产和生产力造成损害. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p103]
- “制度”在整体上滞后于“技术和科学”的思想是启蒙运动中自由主义的延续. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p103]
