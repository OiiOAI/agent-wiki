# Network Effects

## Summary

Network effects occur when the value of a product or service rises as more people use it. Unlike economies of scale that drive down unit costs, network effects drive up the value of the product. Bill Gates learned about network effects from a 1974 Harvard economics course and used them to make Microsoft Altair BASIC a de facto standard even though it was widely pirated. Google, Facebook, Twitter, and other web platforms have some of the strongest network effects seen. Platforms are a special case with two-sided network effects, connecting buyers and sellers. Airbnb built listings first then renters; Uber connects drivers with riders. Network effects create quasi-monopolies that are hard to disrupt without significant technology or law changes.

- Network effects drive up the value of a product as more people use it, whereas economies of scale drive down unit costs. [raw/books/strategy/The Crux - Richard Rumelt.pdf#p186]

- Airbnb built its platform by first creating listings, raiding Craigslist for them, and subsidizing early listings with professional photography. [raw/books/strategy/The Crux - Richard Rumelt.pdf#p188]
- Uber lost $6.77 billion in 2020, improving from an $8.5 billion loss in 2019, with uncertainty about whether its pricing structure is sustainable. [raw/books/strategy/The Crux - Richard Rumelt.pdf#p188]

- Inference: Platforms like Airbnb and Uber have two-sided network effects, requiring strategic decisions about which side to build first.
