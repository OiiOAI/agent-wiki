# 人类工程

## Summary

人类工程是米尔斯在第五章中批判的概念，指的是将社会科学应用于控制和操纵人类行为的目标。这一概念与技术治国论的政治哲学密切相关，体现了将人视为可操纵客体的观点。米尔斯认为接受人类工程师的角色意味着接受科层制视角，在尚未建立成熟民主制度的美国社会中是不合适的。

## Key facts

- 「人类工程」是一个未被定义的术语，但往往被误认为是一个明确而清晰可见的目标. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p130]
- 人类工程以「控制自然」和「控制社会」之间不容辩驳的类比为基础. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p130]
- 人类工程师设想要努力接触社会，就像物理学家接触自然界一样. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p130]
- 人类工程师的政治哲学包含如下简单观点：要是科学的方法被应用于控制社会行为，人类的问题将迅速得到解决. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p130]
- 如果有人接受专家治国的观点并作为一名社会科学家力图为之有所行动，也就是按照他「好像真是一名人类工程师」一样行动. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p132]
- 在美国这样的社会中，根据「好像我是一名人类工程师」的方式行动，也许只是一场闹剧. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p132]
- 人类工程师的口号带来了超越思想风格和探究方法之上的科层制气质. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p132]
