# Memory Reconsolidation

## Summary

Memory reconsolidation is the process by which a retrieved memory becomes labile and must be stabilized again to persist. When a memory is retrieved, it enters a window of vulnerability during which it can be disrupted by protein synthesis inhibition or updated with new information. This phenomenon, demonstrated in the lateral amygdala for threat memories, suggests that memories are not permanently stored but can be modified or erased when reactivated under specific conditions.

## Key facts

- Blockade of protein synthesis in the lateral amygdala during memory retrieval disrupts the memory when tested the next day. [raw/books/neuroscience/Anxious - Joseph LeDoux.pdf#p417]
- Strong threat memories can undergo reconsolidation if new information is incorporated during retrieval. [raw/books/neuroscience/Anxious - Joseph LeDoux.pdf#p419]
- The reconsolidation window typically lasts approximately 4-6 hours after memory retrieval. [raw/books/neuroscience/Anxious - Joseph LeDoux.pdf#p424]
- In its early stages, long-term memory storage is dynamic and can be disrupted; a memory trace can become labile after retrieval and require an additional round of consolidation. [raw/books/neuroscience/Eric Kandel PRINCIPLES OF NEURAL SCIENCE Sixth Edition - Eric R Kandel; John Koester; Sarah Mack; Steven Siegelbaum.pdf#p1375]
- Retrieved memory in Aplysia becomes labile through ubiquitin-mediated protein degradation and is reconsolidated by new protein synthesis. [raw/books/neuroscience/Eric Kandel PRINCIPLES OF NEURAL SCIENCE Sixth Edition - Eric R Kandel; John Koester; Sarah Mack; Steven Siegelbaum.pdf#p1375]
- When a synapse that has undergone long-term facilitation is reactivated by a brief burst of presynaptic action potentials, it becomes destabilized through protein degradation and requires protein synthesis for restabilization. [raw/books/neuroscience/Eric Kandel PRINCIPLES OF NEURAL SCIENCE Sixth Edition - Eric R Kandel; John Koester; Sarah Mack; Steven Siegelbaum.pdf#p1375]

## Inferences

- Inference: Because retrieval reopens consolidation, therapeutic interventions that target memories during this vulnerable window could potentially modify pathological memories in anxiety disorders and PTSD.
- Inference: Reconsolidation involves restabilization of synaptic facilitation at the same synapses at which the initial memory was stored, suggesting that memories remain at least partially localized at specific synapses.
