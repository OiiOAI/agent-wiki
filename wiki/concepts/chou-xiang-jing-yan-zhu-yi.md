# 抽象经验主义

## Summary

抽象经验主义是C.赖特·米尔斯在《社会学的想象力》第三章中批判的一种社会科学研究风格。其特征包括：以抽样访谈为基本数据来源；使用标准化分类和霍勒里斯代码卡片进行统计处理；通过变量关系分析得出统计判断。该风格主要关注舆论、选举行为等主题，但米尔斯批评其回避社会科学的真正使命，与宏大理论同样逃避了对社会结构问题的深入探讨。

## Key facts

- 抽象经验主义的基本数据来源是对抽样挑选出的人群所进行的访谈. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p62]
- 访谈对象的回答经过标准分类，被键入霍勒里斯代码卡片，并通过找出变量之间的关系进行统计. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p62]
- 抽象经验主义的研究结果通常以统计判断的形式表示，在复杂层面上解答被组合进繁复的交互分类之中. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p62]
- 舆论是绝大多数抽象经验主义风格研究的主题. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p63]
- 抽象经验主义有把研究对象和用来研究它的方法相混淆的倾向. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p63]
- 大多数有关舆论的研究是在美国单一民族的社会结构中进行的，并且也只是着眼于近十年来的状况. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p63]
- 抽象经验主义者所试图解决的问题，如大众传媒的影响，如果没有结构情境就无法予以充分陈述. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p64]
- 在研究政治生活的这一学派中，选举行为一直是其最核心的问题. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p64]
- 抽象经验主义更关注科学哲学，而非社会研究本身. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p69]
- 抽象经验主义最具决定性的结果是造成了方法论的抑制. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p69]
- 抽象经验主义的技术方法及其科层式的运用目前一般结为一体. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p116]
- 从事抽象经验主义研究费用很高，只有大组织才能轻松承担，包括财团、军队、政权机构及其附属. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p118]

- 从事抽象经验主义的社会学家通常不为「公众」发言，而有自己特定的服务对象. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p118]
- 抽象经验主义的追随者往往不太关注设定自己的根本性问题. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p118]
- 抽象经验主义的研究方式关注实用性，其研究组织倾向于选择和训练特定的心智品质. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p122]

- 抽象经验主义者解决指标问题的方式往往是对于已建立指标的思想，清除其适用的范围和内在意义. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p140]

## Inferences

- Inference: 抽象经验主义的哲学基础主要从自然科学哲学借鉴而来，而非从社会科学研究的经典思路中产生
- Inference: 抽象经验主义往往表现出心理主义的偏向，倾向于避开结构问题，偏爱情境问题
- Inference: 米尔斯认为抽象经验主义和宏大理论都无法产生真正有成果的思想，它们都靠社会科学的经典传统过活。

## Uncertainties

- Uncertain: 拉扎斯菲尔德所提出的从社会哲学到经验社会科学的转变方案，究竟是事实描述还是规范性建议，米尔斯认为尚不明确
