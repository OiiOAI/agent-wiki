# Game Without End

## Summary

A system that cannot generate from within itself the conditions for its own change because it contains no provisions for termination. Such games can run through all possible internal changes without achieving systemic change. The authors contrast games-without-end with games that have built-in end points. The concept derives from Gödel's undecidability theorem: any system complex enough to include arithmetic cannot prove its own consistency from within. Termination (like waking from a nightmare) is meta to the game, of a different logical type than any move within the game.
