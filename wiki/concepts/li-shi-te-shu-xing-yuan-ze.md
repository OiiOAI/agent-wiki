# 历史特殊性原则

## Summary

历史特殊性原则是米尔斯在本书中提出的核心理论主张。该原则认为任何一个给定社会都要根据它所存在的特定时代来理解，社会的表象具有其历史特殊性。历史变迁就是社会结构的变迁，不同的社会结构对应不同的变迁机制和原则。这一原则要求社会科学研究必须具备历史视野，将研究对象置于特定的历史情境中理解。

## Key facts

- 马克思所谓的'历史特殊性原则'首先指的就是这样一种方针：任何一个给定社会都要根据它所存在的特定时代来理解. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p168]
- 在给定时代流行的制度、意识形态、各种类型的男女众生都构成了某种具有独一无二模式的东西. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p168]
- 历史变迁就是社会结构的变迁，它们的组成部分之间相互关系的变迁. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p169]
- 历史特殊性的原则适用于社会科学，同样也适用于心理学. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p183]
- 对人作为人来说，有某些普遍的'人性'存在的思想违背了社会和历史的特殊性. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p184]

## Inferences

- Inference: 米尔斯认为，不存在超越历史的普遍社会法则；所谓'社会法则'或'社会规律性'的真正含义是在某个特定历史时期去发现或建构'主导媒体'之类的东西
