# SI base units

## Summary

The seven fundamental units of the International System of Units (SI): meter for length, kilogram for mass, second for time, ampere for electric current, kelvin for thermodynamic temperature, candela for luminous intensity, and mole for amount of substance. These base units are used to derive all other SI units.

## Key facts

- The seven SI base units are: meter (m), kilogram (kg), second (s), ampere (A), kelvin (K), candela (cd), and mole (mol). [raw/books/strategy/How_to_Measure_Anything.epub#L2620-L2620]
- Supplementary SI units include radian (rad) for plane angle and steradian (sr) for solid angle. [raw/books/strategy/How_to_Measure_Anything.epub#L2620-L2620]
- SI prefixes range from yocto (10⁻²⁴) to yotta (10²⁴). [raw/books/strategy/How_to_Measure_Anything.epub#L2620-L2620]

## Inferences

- Inference: All other SI derived units (joule, watt, pascal, etc.) are constructed from these seven base units through algebraic combinations.
