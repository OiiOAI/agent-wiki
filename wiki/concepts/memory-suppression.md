# Memory Suppression

## Summary

Memory suppression, studied using the think-no-think paradigm, involves intentionally preventing unwanted memories from entering conscious awareness. Research indicates that PTSD patients have impaired memory suppression abilities, and that training suppression may help reduce intrusive traumatic memories without producing the 'white bear' rebound effect seen in simple thought suppression.

## Key facts

- PTSD patients show significantly greater impairment in suppression-induced forgetting than trauma-exposed controls without PTSD, with severity correlating with suppression deficits. [raw/books/neuroscience/The Seven Sins of Memory - Daniel L. Schacter.pdf#p246]
- Healthy individuals with impaired suppression on the think-no-think task report more distress from intrusive memories after watching emotionally upsetting films. [raw/books/neuroscience/The Seven Sins of Memory - Daniel L. Schacter.pdf#p246]
- Anderson argues the think-no-think procedure avoids the 'white bear' rebound effect because participants focus on the cue word without needing to explicitly think about the to-be-suppressed item. [raw/books/neuroscience/The Seven Sins of Memory - Daniel L. Schacter.pdf#p246]
- Depressed individuals show modest deficits in memory suppression and recruit different brain regions than nondepressed individuals during suppression. [raw/books/neuroscience/The Seven Sins of Memory - Daniel L. Schacter.pdf#p272]
