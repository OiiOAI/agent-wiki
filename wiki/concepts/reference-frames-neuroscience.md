# Reference Frames (Neuroscience)

## Summary

In the Thousand Brains Theory, reference frames are map-like structures in cortical columns that store knowledge about objects, concepts, and the body. They provide the substrate for learning the structure of the world, enabling the brain to model 3D objects, make predictions, create plans, and perform movements.

## Key facts

- Each cortical column creates reference frames for every object it knows, populating them with links to other reference frames in a nested hierarchy. [raw/books/neuroscience/A Thousand Brains _ A New Theory of Intelligence - Jeff Hawkins; Richard Dawkins; Basic Books.pdf#p89]
- The brain models the world using reference frames that are populated with reference frames—reference frames all the way down. [raw/books/neuroscience/A Thousand Brains _ A New Theory of Intelligence - Jeff Hawkins; Richard Dawkins; Basic Books.pdf#p89]
- To learn a new combined object (e.g., a coffee cup with a logo), a column creates a new reference frame containing links to the reference frames of the component objects. [raw/books/neuroscience/A Thousand Brains _ A New Theory of Intelligence - Jeff Hawkins; Richard Dawkins; Basic Books.pdf#p89]
- Reference frames in what columns learn maps of physical objects, where columns learn maps of space, and non-sensory columns learn maps of concepts. [raw/books/neuroscience/A Thousand Brains _ A New Theory of Intelligence - Jeff Hawkins; Richard Dawkins; Basic Books.pdf#p90]
- Expertise in any domain requires having a good reference frame, a good map—different people can arrange the same facts in different reference frames leading to different worldviews. [raw/books/neuroscience/A Thousand Brains _ A New Theory of Intelligence - Jeff Hawkins; Richard Dawkins; Basic Books.pdf#p90]
- Thinking occurs as the brain activates one location at a time in a reference frame and the associated piece of knowledge is retrieved. [raw/books/neuroscience/A Thousand Brains _ A New Theory of Intelligence - Jeff Hawkins; Richard Dawkins; Basic Books.pdf#p127]

## Inferences

- Inference: Reference frames enable rapid learning of new combinations because previously learned components do not need to be relearned—they are simply linked.

## Uncertainties

- Uncertain: The exact neural implementation of how reference frames are created and maintained is still being researched.
