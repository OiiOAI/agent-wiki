# 方法论的抑制

## Summary

方法论的抑制是米尔斯在批判抽象经验主义时提出的核心概念，指科学方法被严格限定于人们所选择研究的问题和表述问题的方式，导致方法论似乎决定了问题本身。这种抑制使研究者被困于方法的认识论问题，而忽视了对经验资料的实质性吸收，阻碍了对社会结构等重大问题的探讨。

## Key facts

- 方法论的抑制指科学方法严格限定了人们所选择研究的问题和表述问题的方式. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p69]
- 抽象经验主义的科学方法主要从自然科学哲学借鉴而来，并对之做了些权宜性的修正. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p69]
- 在方法论的抑制中，人们更多地被困于方法的认识论问题，而不是对经验资料的吸收. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p86]
- 那些囿于方法论抑制的人往往拒绝评论当代社会，除非它已经过统计仪式这一小而精的程序操作. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p83]
