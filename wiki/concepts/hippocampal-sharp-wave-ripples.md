# Hippocampal sharp-wave ripples

## Summary

Hippocampal sharp-wave ripples are brief, high-frequency oscillatory events in the hippocampus that occur predominantly during NREM sleep. These events are associated with the replay of memory sequences and are believed to be critical for memory consolidation.

## Key facts

- Memory reactivation in animal models has most consistently been observed during periods of NREM sleep during brief hippocampal sharp-wave ripple burst events. [raw/books/neuroscience/wamsley__stickgold_sleep_medicine_clinics_2011.pdf#p2]
- Sharp-wave ripples in the hippocampus are associated with memory replay during sleep. [raw/books/neuroscience/wamsley__stickgold_sleep_medicine_clinics_2011.pdf#p2]
