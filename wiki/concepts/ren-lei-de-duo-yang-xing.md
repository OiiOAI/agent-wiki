# 人类的多样性

## Summary

米尔斯认为社会科学应当关注人类的多样性，这种多样性构成了人类过去、现在和未来分别生活于其中的全部社会世界。人类的多样性包括各种社会形态、文化、制度以及个体的多样性。为理解这种多样性，需要一系列既简要又综合的观点，这是社会科学首要和恒久的目的。

## Key facts

- 社会科学应当关注的，是人类的多样性，这种多样性构成了人类过去、现在和未来分别生活于其中的全部社会世界. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p143]
- 人类的多样性包括从历时千年之久而绝少变化的原始社区，到以暴力打开天下的强权国家. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p143]
- 人类的多样性也包含着个体的多样性，包括从公元前的婆罗门到当代玻利维亚的政治家，从古罗马贵族到好莱坞新星. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p144]
- 为达到对人类和社会的有序理解，我们需要一系列观点，它必须足够简要使得理解成为可能，又必须足够的综合使我们在观点中能包含多样性的广度和深度. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p144]
- 为获得此类观点而努力，是社会科学首要和恒久的目的. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p144]

## Inferences

- Inference: 米尔斯认为社会科学的混乱状态并非对研究对象多样性的必然反映，多样性并不比研究程序更无序。理解人类多样性需要研究与历史现实层次的紧密联系。
