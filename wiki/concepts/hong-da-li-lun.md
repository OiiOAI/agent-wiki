# 宏大理论

## Summary

宏大理论是米尔斯在《社会学的想象力》第二章中批判的一种社会理论风格，其典型代表是塔尔科特·帕森斯的《社会系统》。米尔斯认为宏大理论的基本起因是思考的层次太一般化，以至于其实践者们无法合乎逻辑地回落到观察上来。宏大理论在句法学上浑浑噩噩，对语义学也茫然无知，其概念体系排除了人类社会的许多结构性方面，如权力、经济和政治制度。

## Key facts

- 宏大理论的最突出代表是塔尔科特·帕森斯，其著作《社会系统》是帕森斯著作中最为重要的作品. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p33]
- 宏大理论的基本起因是开始思考的层次太一般化，以至于它的实践者们无法合乎逻辑地回落到观察上来. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p42]
- 宏大理论在句法学上浑浑噩噩，对语义学也茫然无知. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p42]
- 宏大理论家们如此迷恋句法意义，对语义的关联性是如此缺乏想像力. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p43]
- 米尔斯将宏大理论的内容总结为：人们往往共享许多标准，并彼此期望坚持它们，如果他们这么做了，他们所在的社会将是有序的. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p35]
- 宏大理论的概念王国排除了人类社会的许多结构性方面，排除了被人们长期以来正确认识为理解人类社会必不可少的方面. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p44]
- 米尔斯认为宏大理论百分之五十只是晦涩的用词，百分之四十是众所周知的教科书社会学，另外百分之十是意识形态上的运用. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p61]
- 如果试图通过宏大理论来逃避常识的经验论，你将把活生生的清楚的经验材料从你所使用的概念中割离出来. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p140]
- 宏大理论不能有效面对指标问题，它只是继续以别的同样抽象的概念来阐释概念. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p140]
- 在宏大理论中，证明是满怀希望的演绎法，但直到现在，似乎证明什么和如何证明都还不是很确定的问题. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p142]
- 宏大理论家的策略是期待某天某地接触到活生生的经验材料，然后“系统性地”运用这些材料. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p144]
- 宏大理论弥补科层化的社会科学的理论贫乏. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p146]

## Inferences

- Inference: 米尔斯对宏大理论的批评主要集中在三个方面：抽象层次过高导致无法连接经验观察；规范性结构的自主性假设排除了权力和冲突；系统性和谐的假设排除了社会变迁的可能性
- Inference: 米尔斯认为宏大理论与抽象经验主义代表了两种逃避常识经验论的方式，但都走向了极端，需要在经典社会科学的传统中寻求平衡。

## Uncertainties

- Uncertain: 米尔斯提到帕森斯相信社会科学无法得到关于历史本身是如何发生的系统性思想，但这是否代表帕森斯的最终立场存在争议
