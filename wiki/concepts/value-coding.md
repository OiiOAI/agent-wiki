# Value Coding

## Summary

Value coding refers to the neural representation of reward-related information that guides choice behavior. Research across multiple brain regions including the lateral intraparietal area (LIP), orbitofrontal cortex, dorsolateral prefrontal cortex, and basal ganglia demonstrates that neural activity correlates with behaviorally inferred estimates of subjective value. A key finding is that value representation follows a relative coding scheme mediated by divisive normalization, where neural responses are modulated by the value of both selected and alternative options.

## Key facts

- Reward-related responses are evident in many different brain areas, and a key step in examining neural value coding is distinguishing decision-related value representation from other forms of reward-related activity. [raw/books/neuroscience/Decision Neuroscience _ An Integrative Perspective - Jean - Claude Dreher; Léon Tremblay; Institut de sciences.pdf#p123]
- Electrophysiological and neuroimaging data show that neural activity in a number of brain areas correlates with behaviorally inferred estimates of subjective value. [raw/books/neuroscience/Decision Neuroscience _ An Integrative Perspective - Jean - Claude Dreher; Léon Tremblay; Institut de sciences.pdf#p123]
- Midbrain dopaminergic neurons reflect reward prediction error, a quantity encoding the difference between expected and received reward value. [raw/books/neuroscience/Decision Neuroscience _ An Integrative Perspective - Jean - Claude Dreher; Léon Tremblay; Institut de sciences.pdf#p123]
- Value coding in LIP is mediated by divisive normalization, where activation by response field target value is combined with suppression driven by the value of extra-RF targets. [raw/books/neuroscience/Decision Neuroscience _ An Integrative Perspective - Jean - Claude Dreher; Léon Tremblay; Institut de sciences.pdf#p128]
- Contextual value modulation is consistent with the effect of choice set size and target uncertainty in reducing firing rates in downstream motor structures like the superior colliculus. [raw/books/neuroscience/Decision Neuroscience _ An Integrative Perspective - Jean - Claude Dreher; Léon Tremblay; Institut de sciences.pdf#p127]

## Inferences

- Inference: Value functions used in reinforcement learning models may be explicitly coded in neural activity and play a critical role in the biological decision process.
- Inference: The neural representation of subjective value through relative value coding may underlie risk-averse choice behavior, as compressive utility functions model such behavior and divisive normalization produces saturating responses.

## Uncertainties

- Uncertain: The relationship between neural value signals and theoretical value quantities defined by behavioral choice theories remains to be fully characterized.
