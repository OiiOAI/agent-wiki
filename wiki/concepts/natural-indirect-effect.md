# Natural Indirect Effect (NIE)

## Summary

The Natural Indirect Effect (NIE) measures the portion of the effect of X on Y that operates through a specific mediator M. It compares outcomes when the mediator is set to the value it would have under treatment versus the value it would have under no treatment, while holding X constant. NIE cannot be expressed using do-operators alone and requires counterfactual notation, but the Mediation Formula enables its estimation from observational data.

## Key facts

- NIE measures the effect transmitted through the mediator while X is held constant. [raw/books/strategy/The_Book_of_Why.epub#L2848-L2855]
- NIE requires double-nested counterfactuals (what would have happened if X had been different and M had taken the value it would have under different X). [raw/books/strategy/The_Book_of_Why.epub#L2865-L2875]
- There is no 'controlled' version of indirect effect because there is no way to disable the direct path by holding some variable constant. [raw/books/strategy/The_Book_of_Why.epub#L2848-L2852]

## Inferences

- Inference: The conceptual difficulty of NIE explains why statisticians struggled for decades to define indirect effects precisely.
