# 心理主义

## Summary

心理主义是米尔斯对抽象经验主义研究倾向的批评性概念，指在解释社会现象时运用个体性格方面的事实和理论，将社会结构现实还原为个体心理因素。该倾向基于这样的认识：通过研究一系列的个体和他们所处的环境，研究结论可以以某种方式汇入关于社会结构的认识，但其后果是回避了系统的历史研究和比较研究。

- 心理主义指在解释社会现象时运用个体性格方面的事实和理论. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p88]
- 作为一种学说，心理主义乃是基于对社会结构现实的形而上学的明确否认. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p88]
- 抽象经验主义基本的信息来源于对个体的抽样，提出的问题以个体心理反应的术语表达. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p79]
- 心理主义与结构视角直接对立，因为处于环境中的人往往并不觉察引起环境变化的原因，只有以结构转换的方式才能理解这些变化. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p80]
