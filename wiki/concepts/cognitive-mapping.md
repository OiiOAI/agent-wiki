# Cognitive Mapping

## Summary

Cognitive mapping is Jameson's proposed solution to the problem of disorientation in postmodern society. He argues that we need cognitive maps to find our way around the multinational capitalist system and cultural explosion. Jameson links this to Marxian theory, specifically viewing cognitive mapping as a code word for 'class consciousness' adapted to postmodern spatial conditions. [raw/books/sociology/现代社会学理论 - 第7版 - 美 - 乔治 - 瑞泽尔 - 后浪大学堂 - 2018.pdf#p526]
