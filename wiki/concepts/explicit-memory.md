# Explicit Memory

## Summary

Explicit (or declarative) memory is conscious recall of people, places, objects, facts, and events—the type of memory that H.M. lacked. Brenda Milner's studies showed that explicit memory requires the hippocampus and medial temporal lobe for converting new short-term memories into long-term storage. Unlike implicit memory, explicit memory involves awareness of remembering and is ultimately stored in the same areas of cerebral cortex that originally processed the information.

## Key facts

- Explicit memory is the conscious recall of people, places, objects, facts, and events. [raw/books/neuroscience/In Search of Memory_ The Emergence of a Ne - Eric R. Kandel.pdf#p144]
- Milner showed that explicit memory requires the hippocampus and medial temporal lobe for converting short-term to long-term storage. [raw/books/neuroscience/In Search of Memory_ The Emergence of a Ne - Eric R. Kandel.pdf#p141]
- Long-term explicit memories are stored in the cerebral cortex, in the same areas that originally processed the information—visual memories in visual cortex, tactile memories in somatosensory cortex. [raw/books/neuroscience/In Search of Memory_ The Emergence of a Ne - Eric R. Kandel.pdf#p142]
- Explicit memory makes it possible to leap across space and time and conjure up events and emotional states that have vanished into the past. [raw/books/neuroscience/In Search of Memory_ The Emergence of a Ne - Eric R. Kandel.pdf#p292]
- Recalling a memory episodically is not like simply turning to a photograph in an album; recall of memory is a creative process. [raw/books/neuroscience/In Search of Memory_ The Emergence of a Ne - Eric R. Kandel.pdf#p292]
- What the brain stores is thought to be only a core memory; upon recall, this core memory is elaborated upon and reconstructed, with subtractions, additions, elaborations, and distortions. [raw/books/neuroscience/In Search of Memory_ The Emergence of a Ne - Eric R. Kandel.pdf#p292]
- Explicit memory requires selective attention for encoding and for recall. [raw/books/neuroscience/In Search of Memory_ The Emergence of a Ne - Eric R. Kandel.pdf#p321]
- Explicit memory involves conscious retrieval of previous experiences and conscious recall of factual knowledge, enabling flexible association of multiple pieces of information. [raw/books/neuroscience/Principles of Neural Science, Fifth Edition (Principles of - Eric R_ Kandel; James H_ Schwartz; Thomas M_ Jessell; Steven.pdf#p1453]
- Explicit memory can be subdivided into episodic memory (memory of personal experiences/autobiographical) and semantic memory (memory for facts). [raw/books/neuroscience/Principles of Neural Science, Fifth Edition (Principles of - Eric R_ Kandel; James H_ Schwartz; Thomas M_ Jessell; Steven.pdf#p1453]
- Explicit memory processing involves four distinct operations: encoding, storage, consolidation, and retrieval. [raw/books/neuroscience/Principles of Neural Science, Fifth Edition (Principles of - Eric R_ Kandel; James H_ Schwartz; Thomas M_ Jessell; Steven.pdf#p1453]
- Functional MRI studies show greater activity in the medial temporal lobe during encoding of stimuli that are subsequently remembered compared to those forgotten. [raw/books/neuroscience/Principles of Neural Science, Fifth Edition (Principles of - Eric R_ Kandel; James H_ Schwartz; Thomas M_ Jessell; Steven.pdf#p1499]
- Old memories are not stored in the medial temporal lobe; rather, they are stored in various cortical regions and can be retrieved directly after consolidation is complete. [raw/books/neuroscience/Principles of Neural Science, Fifth Edition (Principles of - Eric R_ Kandel; James H_ Schwartz; Thomas M_ Jessell; Steven.pdf#p1453]

## Inferences

- Inference: The distinction between explicit and implicit memory, anticipated by philosophers like Helmholtz, William James, and Gilbert Ryle, was first demonstrated biologically by Milner's studies on H.M.
- Inference: The text notes that explicit memory storage is widely distributed among many brain regions and can be accessed independently by visual, verbal, or other sensory clues, suggesting multiple pathways to retrieve the same information.
