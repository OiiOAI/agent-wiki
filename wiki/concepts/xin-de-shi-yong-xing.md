# 新的实用性

## Summary

新的实用性是相对于旧的自由主义实用性的学术回应，它将自由主义更变成福利国家对社会服务的行政管理，而非改革运动。社会科学被在公司、军队和国家政权中被保守主义者保守地运用。人们认为，能够为实现大制度目标服务的东西才是“实用的”。这一转变标志着社会科学家从面向发起改革的运动家到面向决策层的转变。

## Key facts

- 新的实用性将自由主义变成福利国家对社会服务的行政管理，而非改革运动. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p109]
- 在社会科学家们的学科史上，他们第一次与比福利机构和农业与家政顾问层次高得多的私人及公共权力建立了专业上的联系. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p109]
- 新实用性的社会科学家研究的问题从自己选择的问题转变为新主顾们的问题. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p109]
- 新的保守主义实用性安置于工业关系中心、大学的研究部门、新的公司研究机构、空军和政府之中. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p109]
- 世故的保守主义者需要能证明其权力正当性的新的符号，他们以出于保守目的而运用自由主义符号著称. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p110]
