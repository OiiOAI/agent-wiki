# Value Function

## Summary

The value function in Prospect Theory describes the subjective evaluation of outcomes as deviations from a reference point. It is concave for gains (diminishing sensitivity) and convex for losses, with the loss limb being steeper than the gain limb. The power function parameterization v(x) = x^α for gains and v(x) = -λ(-x)^β for losses is commonly used.

## Key facts

- The value function is concave for gains and convex for losses, reflecting diminishing sensitivity relative to the reference point. [raw/books/neuroscience/Neuroeconomics _ Decision Making and the Brain - Paul W_ Glimcher, Ernst Fehr, Colin Camerer, Antonio Rangel,.pdf#p143]
- Tversky and Kahneman (1992) estimated median values of α = 0.88, β = 0.88, and λ = 2.25 for the power value function. [raw/books/neuroscience/Neuroeconomics _ Decision Making and the Brain - Paul W_ Glimcher, Ernst Fehr, Colin Camerer, Antonio Rangel,.pdf#p149]
- Preference homotheticity assumes that as the stakes of a prospect are multiplied by a constant, so is its certainty equivalent, but this only holds within an order of magnitude.
