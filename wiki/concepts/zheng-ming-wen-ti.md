# 证明问题

## Summary

米尔斯区分了三种研究传统中“证明”的含义：抽象经验主义关注“如何证明”，宏大理论依赖“演绎法”但缺乏确定性，经典社会科学则将“证明什么”与“如何证明”视为同等重要。证明意味着要以理性说服别人，要求每个研究步骤开放以接受检验。

## Key facts

- 经验主义的证明问题是“怎样抓取事实”而不是为事实所淹没，怎样使思想和事实紧密联系在一块而不是使思想脱离事实. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p142]
- 在抽象经验主义中，证明什么似乎往往不作为一个很正式的问题，而如何证明则几乎由问题被表述的方式自动提供. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p142]
- 在经典实践中，证明什么通常被认为与如何证明一样重要，甚至可能比之更重要. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p142]
- 证明意味着要以理性说服别人，研究应以每个步骤都开放接受别人检验的方式进行. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p143]

## Inferences

- Inference: 米尔斯强调经典社会科学通过细致解释彼此关联的所有经验材料来证明陈述，并认为所有猜测的正确率并不相等，经典社会科学的目的就是提高对重要事情猜测的正确率。
