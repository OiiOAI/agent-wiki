# 个人困扰

## Summary

个人困扰产生于个体的性格之中，产生于他与别人的直接联系之中，这些困扰与他自身有关，也与他个人所直接了解的有限的社会生活范围有关。困扰的表述及解决有赖于个人的生活经历整体和切身所处的环境。困扰是桩私人事务，个人感到自己珍视的价值受到了威胁。在当代，当人们不知什么是其珍视的价值，但却仍明显地觉察到威胁时，就会产生焦虑的体验。

## Key facts

- 困扰产生于个体的性格之中，产生于他与别人的直接联系之中，与他自身有关，也与他个人所直接了解的有限的社会生活范围有关. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p14]
- 表述及解决困扰有赖于个人的生活经历是一个整体，有赖于他切身所处的环境，即个人经历和在一定程度上意志活动所直接接触的社会环境. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p14]
- 困扰是桩私人事务：个人感到自己珍视的价值受到了威胁. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p14]
- 当人们珍视某些价值而尚未感到它们受到威胁时，他们会体会到幸福. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p17]

## Inferences

- Inference: 米尔斯指出，在当代许多人的困扰往往只是感到处于困境，有说不清楚的焦虑，却不知用根据价值和威胁来定义的困扰来形容它，说明普通人往往不能清晰地界定自己的个人困扰
