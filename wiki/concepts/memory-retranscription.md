# Memory Retranscription

## Summary

Memory retranscription is Freud's concept that memories are not permanently engraved but can be altered by subsequent events and re-recorded. What is new about this theory is that memory is present multiple times over, constantly remodeled like a nation's legends about its early history. For traumatic memories to change, they must become conscious and the focus of attention.

## Key facts

- Freud observed that memories are not written down once or engraved to remain unchanged forever but can be altered by subsequent events and retranscribed. [raw/books/neuroscience/The Brain That Changes Itself - Norman Doidge.pdf#p229]
- In 1896 Freud wrote that memory traces are subjected to 'a rearrangement in accordance with fresh circumstances—to a retranscription,' and memory is present not once but several times over. [raw/books/neuroscience/The Brain That Changes Itself - Norman Doidge.pdf#p230]
- Freud argued memories are constantly remodeled, 'analogous in every way to the process by which a nation constructs legends about its early history.'. [raw/books/neuroscience/The Brain That Changes Itself - Norman Doidge.pdf#p230]
- Freud argued that for memories to be changed, they had to be conscious and become the focus of conscious attention, as neuroscientists have since confirmed. [raw/books/neuroscience/The Brain That Changes Itself - Norman Doidge.pdf#p230]
- Traumatic memories of early childhood events are not easily accessible to consciousness, so they don't easily change without therapeutic intervention. [raw/books/neuroscience/The Brain That Changes Itself - Norman Doidge.pdf#p230]
- Analysis plastically retranscribes procedural memories into conscious explicit memories, sometimes for the first time, so patients no longer need to relive or reenact them. [raw/books/neuroscience/The Brain That Changes Itself - Norman Doidge.pdf#p235]
- The book argues that we can transform implicit memories—which seem to come 'out of the blue'—into declarative memories with clear context, making them easier to recollect and experience as part of the past. [raw/books/neuroscience/The Brain That Changes Itself - Norman Doidge.pdf#p248]
