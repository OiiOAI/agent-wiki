# Grid Layout

## Summary

Grid layout is a design technique developed in Switzerland in the late 1940s for arranging graphical elements. It involves placing text, images, and graphics within a grid of equally sized rectangles separated by corridors. This system improves the visual organization of slides, posters, and documents by ensuring alignment and hierarchy.

## Key facts

- The grid system was developed in Switzerland in the late 1940s. [raw/books/strategy/Make it Clear - Patrick Henry Winston.pdf#p271]
- A 4x3 grid offers 12 rectangle size choices for placing elements. [raw/books/strategy/Make it Clear - Patrick Henry Winston.pdf#p272]
- An 8x6 grid offers 48 rectangle size choices. [raw/books/strategy/Make it Clear - Patrick Henry Winston.pdf#p272]
- The corridors between rectangles offer convenient places for captions. [raw/books/strategy/Make it Clear - Patrick Henry Winston.pdf#p275]
