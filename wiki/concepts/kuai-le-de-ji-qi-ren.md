# 快乐的机器人

## Summary

"快乐的机器人"是米尔斯提出的关于当代自由问题终极形式的核心概念。他提出：在当代人中，所谓的"快乐的机器人"会逐渐流行甚至兴盛于世吗？这种人具有合理性但没有理性，不断自我合理化却越来越焦虑不安。米尔斯认为，自由的终极问题是：人性中的什么东西使快乐的机器人渐趋流行？又有什么东西来抗拒这一潮流？

## Key facts

- 米尔斯提出终极问题：在当代人中，所谓的"快乐的机器人"会逐渐流行甚至兴盛于世吗？. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p191]
- 借助化学和精神治疗，通过稳定压力和控制环境，可以把人变为机器人. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p192]
- 异化的人是西方人关于自由的人的意象的对立面，这种人充斥其间的社会是自由社会或"民主"社会的对立面. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p194]
- 并非所有人都自然而然地企求自由，也并非所有人都愿意尽全力或能够尽全力获得自由所必需的理性. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p197]

## Inferences

- Inference: 米尔斯认为"快乐的机器人"的出现意味着没有理性的合理性，意味着人的异化，意味着理性在人类事务中并没有自由发挥作用

## Uncertainties

- Uncertain: 快乐的机器人是否真的会"心甘情愿"并感到"幸福"，这种幸福的涵义与品质是什么，米尔斯承认不知道答案
