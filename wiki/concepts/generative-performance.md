# Generative performance

## Summary

Generative performance refers to the ability of a model to generate realistic patterns of behavior in simulated experiments, rather than merely predicting average choice outcomes. It is needed when the environment or subject state has temporal dynamics (e.g., foraging tasks, reversal learning, exploration-exploitation tasks). Predictive performance is insufficient in such settings because models can appear to predict well on average while generating unrealistic dynamics. Evaluating generative performance involves comparing real data with synthetic data generated by the model, looking for discrepancies in task-specific dynamics. The ideal test is a 'Turing test' for behavioral models: if experimenters cannot distinguish model-generated data from subject-generated data using behavioral measures of interest, the model is presumably adequate.

- Predictive performance evaluates average accuracy in predicting choices, but is insufficient when the environment has temporal dynamics, because a model could predict averages accurately while generating unrealistic patterns of behavior.
