# Associative Memory

## Summary

Associative memory networks use Hebbian plasticity to store and recall neural activity patterns. Information transfers from neural activity to synaptic connections through correlated activation, and recall occurs when partial patterns trigger completion of the entire stored pattern.

## Key facts

- Associative memory networks assume information is transferred back and forth between neural activity and synaptic connections through Hebbian plasticity. [raw/books/neuroscience/Principles of Neural Science, Fifth Edition (Principles of - Eric R_ Kandel; James H_ Schwartz; Thomas M_ Jessell; Steven.pdf#p1644]
- In associative memory networks, synaptic strengths are specified by a correlation matrix based on the statistical correlations between neural activities. [raw/books/neuroscience/Principles of Neural Science, Fifth Edition (Principles of - Eric R_ Kandel; James H_ Schwartz; Thomas M_ Jessell; Steven.pdf#p1645]
- The Hopfield network uses symmetric connections so that the network dynamics minimize an energy-like function, converging to stable attractor states representing stored memories. [raw/books/neuroscience/Principles of Neural Science, Fifth Edition (Principles of - Eric R_ Kandel; James H_ Schwartz; Thomas M_ Jessell; Steven.pdf#p1648]
- Nonoverlapping cell assemblies do not interfere with each other, and the number of patterns that can be stored equals total neurons divided by assembly size. [raw/books/neuroscience/Principles of Neural Science, Fifth Edition (Principles of - Eric R_ Kandel; James H_ Schwartz; Thomas M_ Jessell; Steven.pdf#p1647]

## Inferences

- Inference: Symmetric networks that minimize energy-like functions can store multiple attractor states representing different memories.
