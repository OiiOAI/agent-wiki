# 技巧、价值与感性

## Summary

米尔斯区分了教育中的三个层面：技巧（读写或操作机床等可训练的能力）、价值（帮助人确定真正想要什么、讨论生活方式）、以及感性（包含前两者更多内容，涵盖自我认识的疗法和辩论技巧的训练）。感性是最能激起兴趣的部分。

## Key facts

- 培训一个人读写或操作机床，很大程度上是一种技巧的训练；而帮助某人确定他真正想从生活中得到什么，或同他辩论斯多葛学派、基督徒和人文主义者的生活方式，则是价值的修养和教育。. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p209]
- 感性包含了从古老意义上说用以澄清人们关于自我认识的疗法，以及争辩技巧的训练。. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p209]
- 大学文科教育的最终产品不外乎自我教育、自我修养的男士女士；简而言之，即自由和理性的个体。. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p210]
