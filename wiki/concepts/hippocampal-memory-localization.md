# Hippocampal Memory Localization

## Summary

Henry Molaison's bilateral medial temporal-lobe resection provided the first causal proof that declarative memory formation is localized to a specific brain region. Before his operation, scientists acknowledged the brain as the seat of conscious memory but had no conclusive evidence that memory was confined to a circumscribed area. Scoville's operation removed tissue including the hippocampus, causing Henry to lose the capacity to convert short-term memories into long-term ones.

## Key facts

- Henry's case provided causal proof that a discrete brain region deep in the temporal lobes is absolutely critical for converting short-term memories into enduring ones. [raw/books/neuroscience/Permanent Present Tense _ The Unforgettable Life of the - Suzanne Corkin.pdf#p350]
- Short-term and long-term memory are separate processes that depend on different brain circuits. [raw/books/neuroscience/Permanent Present Tense _ The Unforgettable Life of the - Suzanne Corkin.pdf#p350]
- A healthy hippocampus is essential for vividly recounting the details of a wedding (recollection), but it is not essential for simply recognizing a face, without identifying it or placing it in a context (familiarity).
