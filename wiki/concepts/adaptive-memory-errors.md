# Adaptive Memory Errors

## Summary

Adaptive memory errors refer to the idea that certain memory distortions and errors arise as by-products of cognitive processes that serve important adaptive functions. This 'vices are also virtues' perspective suggests that the same mechanisms enabling semantic representation, generalization, and episodic simulation also produce false memories, misattributions, and other errors.

## Key facts

- DRM false memories are linked to the left temporal pole, a semantic hub critical for representing meaning—a process that is itself highly adaptive. [raw/books/neuroscience/The Seven Sins of Memory - Daniel L. Schacter.pdf#p273]
- Autistic adults show reduced false recognition of semantic associates alongside preserved true recognition, suggesting their reduced gist-based generalization may limit both false memories and adaptive categorization. [raw/books/neuroscience/The Seven Sins of Memory - Daniel L. Schacter.pdf#p257]
- False memories resulting from suggestibility may be by-products of the normally adaptive process of memory updating. [raw/books/neuroscience/The Seven Sins of Memory - Daniel L. Schacter.pdf#p275]
- Memory errors can result from reconsolidation processes being hijacked by fabricated post-event suggestions to produce false updating. [raw/books/neuroscience/The Seven Sins of Memory - Daniel L. Schacter.pdf#p275]
