# 民族国家

## Summary

米尔斯认为在当代世界，民族国家是研究社会结构最有包容性的单位，是权力等令人关注的方面的主要组织形式。在各民族国家之间及其内部，有效的权力手段和历史创造被严密组织起来。虽然各民族国家地位不同，但它们相互影响且日益自立。

## Key facts

- 在当今世界历史上，民族国家是一种主要的国家形式，同时在每个人生活中也是一个重要的事实. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p146]
- 在民族国家中，政治、军事、文化和经济等方面的决策和权力的手段都是组织化的. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p146]
- 在选择国家的社会结构作为一般性的研究单位之时，我们采用了一个适当的概括层次，使我们得以避免脱离问题，同时又能包容在当代人类行为的许多细节和困扰中明显体现出的结构性力量. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p147]
- 在世界上各个民族国家之间及其内部，有效的权力手段从而在某种程度上历史的创造，被严密地组织起来. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p147]
- 尤其自一战以来，每个民族国家都渐渐自立. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p147]

## Inferences

- Inference: 米尔斯认为大多数社会科学家在严肃考察重要问题时会发现，运用任何一个小于民族国家的研究单位阐述问题都会遇上极大困难。
