# Reference Frames in the Brain

## Summary

Reference frames are maplike coordinate systems that the brain uses to organize all knowledge. Each cortical column creates and manipulates reference frames, which provide the structure for learning the shape and behavior of objects, planning movements, and organizing conceptual knowledge. The brain uses grid cells (like map coordinates) and place cells (like sensory details at each location) to create these reference frames.

## Key facts

- A reference frame is analogous to the grid lines on a map, providing structure that tells you where things are located relative to each other. [raw/books/neuroscience/A Thousand Brains _ A New Theory of Intelligence - Jeff Hawkins; Richard Dawkins; Basic Books.pdf#p17]
- The brain's model of the world is built using hundreds of thousands of reference frames, not just one. [raw/books/neuroscience/A Thousand Brains _ A New Theory of Intelligence - Jeff Hawkins; Richard Dawkins; Basic Books.pdf#p17]
- Most cells in the neocortex are dedicated to creating and manipulating reference frames. [raw/books/neuroscience/A Thousand Brains _ A New Theory of Intelligence - Jeff Hawkins; Richard Dawkins; Basic Books.pdf#p17]
- To predict what fingers will feel when touching a coffee cup, the brain needs to know both the object being touched and the finger's location relative to the cup. [raw/books/neuroscience/A Thousand Brains _ A New Theory of Intelligence - Jeff Hawkins; Richard Dawkins; Basic Books.pdf#p57]
- Reference frames can be attached to objects, to the body, or to abstract concepts. [raw/books/neuroscience/A Thousand Brains _ A New Theory of Intelligence - Jeff Hawkins; Richard Dawkins; Basic Books.pdf#p79]
- Thinking is a form of movement through reference frames, activating successive locations to retrieve stored knowledge. [raw/books/neuroscience/A Thousand Brains _ A New Theory of Intelligence - Jeff Hawkins; Richard Dawkins; Basic Books.pdf#p77]

## Inferences

- Inference: thinking is movement through reference frames, then disorders affecting how reference frames are used or traversed could manifest as cognitive or learning difficulties.

## Uncertainties

- Uncertain: The exact neural implementation of how neurons create and attach reference frames to objects is still being worked out.
- Uncertain: Whether reference frames for abstract concepts use the same neural mechanisms as those for physical objects remains an open question.
