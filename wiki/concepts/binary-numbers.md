# Binary Numbers

## Summary

Binary numbers are sequences of digits in which each digit can have only one of two values, 0 or 1. They can be used to represent objects: 3 bits can represent eight objects, 4 bits can represent sixteen objects, and in general, N bits can represent 2^N objects. Binary numbers are the basic language of computers because they are easy to implement in digital circuits.
