# History Written by the Losers

## Summary

This concept describes how history attributes discoveries and innovations to theorists and academics when in fact practitioners and tinkers discovered them first. Academics write the histories, creating an illusion that theory precedes practice. Taleb documents multiple cases where practitioners had sophisticated techniques centuries before academic formulas.

## Key facts

- Taleb and trader Espen Haug discovered that option pricing sophistication preceded academic formulas by at least a century, developed through natural selection and apprenticeship. [raw/books/strategy/Antifragile_ Things That Gain from Disorde - Taleb, Nassim Nicholas.pdf#p278]
- Chicago pit traders used simple heuristics and refused to use computer output, saying 'real men don't use sheets,' yet produced sophisticated prices that accounted for fat tails which standard formulas ignored. [raw/books/strategy/Antifragile_ Things That Gain from Disorde - Taleb, Nassim Nicholas.pdf#p277]
- Phil Scranton showed that jet engines were built using trial-and-error experiential methods without anyone truly understanding the theory first. [raw/books/strategy/Antifragile_ Things That Gain from Disorde - Taleb, Nassim Nicholas.pdf#p279]
- David Mindell debunked the story that cybernetics was invented by Norbert Wiener in 1948, showing Wiener was articulating feedback control ideas that had long been in practice in engineering. [raw/books/strategy/Antifragile_ Things That Gain from Disorde - Taleb, Nassim Nicholas.pdf#p279]
- Before the thirteenth century, no more than five persons in all of Europe knew how to perform a division, yet architects built cathedrals that are still standing using experimental heuristics and empirical methods. [raw/books/strategy/Antifragile_ Things That Gain from Disorde - Taleb, Nassim Nicholas.pdf#p280]

## Inferences

- Inference: The pattern is so consistent that Taleb proposes the maxim: 'We don't put theories into practice. We create theories out of practice.'
