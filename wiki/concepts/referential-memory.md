# Referential Memory

## Summary

Referential memory is the third type of memory Llinás proposes, alongside working and phylogenetic memory. It allows organisms to hold significant content from the external world within the momentary internal context generated by the thalamocortical system, and to retrieve constructs from memory when predictive demands require them.

## Key facts

- Referential memory allows the detail of significant content of the external world to be held within the momentary internal context generated by the thalamocortical system. [raw/books/neuroscience/I of the Vortex _ From Neurons to Self - Rodolfo Riascos Llinás.pdf#p188]
- The system makes attractors based on repetition—if a pattern of electrical activity has been 'seen' before, it will be recognized better each time. [raw/books/neuroscience/I of the Vortex _ From Neurons to Self - Rodolfo Riascos Llinás.pdf#p188]
- Referential memory can be both short-term (where in the parking lot is my car?) and long-term (the friend who burned my house down). [raw/books/neuroscience/I of the Vortex _ From Neurons to Self - Rodolfo Riascos Llinás.pdf#p189]
- Through repetition and simultaneity, conglomerate activity patterns become associated with particular activity in language-generating areas of the brain. [raw/books/neuroscience/I of the Vortex _ From Neurons to Self - Rodolfo Riascos Llinás.pdf#p188]
