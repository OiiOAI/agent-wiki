# Episodic Recombination

## Summary

Episodic recombination is the cognitive process of flexibly combining elements from different past episodes to create novel simulations of possible future experiences. This process underlies adaptive functions like future planning and problem-solving, while also producing memory errors such as source misattribution and memory conjunction errors.

## Key facts

- Episodic recombination allows people to mentally try out different approaches to novel situations based on past experiences without engaging in actual behavior. [raw/books/neuroscience/The Seven Sins of Memory - Daniel L. Schacter.pdf#p279]
- Studies using the Remote Associates Test show that DRM list exposure boosts problem-solving—but only when participants falsely recall the lure word, linking false memory to creative cognition. [raw/books/neuroscience/The Seven Sins of Memory - Daniel L. Schacter.pdf#p274]
- Correct associative inference (identifying relationships between episodes) increases the likelihood of subsequently misremembering contextual details from those episodes. [raw/books/neuroscience/The Seven Sins of Memory - Daniel L. Schacter.pdf#p280]
