# Declarative vs. Procedural Memory

## Summary

A fundamental division in memory systems: declarative (explicit) memory stores facts and events and depends on the hippocampus, while procedural (implicit) memory stores motor skills and habits and is independent of the hippocampus.

## Key facts

- Declarative memory includes semantic memory (facts, concepts, people, places) and episodic memory (personal experiences and events). [raw/books/neuroscience/The forgetting machine _ memory, perception, and the - Rodrigo Quian Quiroga; hoopla digital.pdf#p123]
- Procedural memory enables skills like riding a bike, tying shoelaces, or driving, and does not depend on the hippocampus. [raw/books/neuroscience/The forgetting machine _ memory, perception, and the - Rodrigo Quian Quiroga; hoopla digital.pdf#p122]
- The case of H.M. provided definitive evidence that the hippocampus is essential for forming new declarative memories but not for procedural learning. [raw/books/neuroscience/The forgetting machine _ memory, perception, and the - Rodrigo Quian Quiroga; hoopla digital.pdf#p122]
- Emotional memories involve the amygdala and are more likely to be remembered due to their emotional charge (flashbulb memories). [raw/books/neuroscience/The forgetting machine _ memory, perception, and the - Rodrigo Quian Quiroga; hoopla digital.pdf#p124]
