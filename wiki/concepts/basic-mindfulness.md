# Basic Mindfulness

## Summary

A comprehensive meditation system created by Shinzen Young and adapted by Michael Taft. It combines concentration, sensory clarity, and acceptance into a structured, secular approach to mindfulness meditation.

## Key facts

- Basic Mindfulness is described as the most comprehensive and industrial-strength meditation system Taft has encountered. [raw/books/psychology/The Mindful Geek_ Secular Meditation for S - Michael Taft.pdf#p9]
- The system was created by Shinzen Young. [raw/books/psychology/The Mindful Geek_ Secular Meditation for S - Michael Taft.pdf#p9]
- Taft altered the system to make it more accessible to 'mindful geeks' and to fit his own teaching style. [raw/books/psychology/The Mindful Geek_ Secular Meditation for S - Michael Taft.pdf#p9]
