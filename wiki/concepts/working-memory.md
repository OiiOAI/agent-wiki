# Working Memory

## Summary

Working memory is a special information-processing function consisting of two main components: a temporary information storage system (the workspace) and a control system that performs executive functions including attention. Attention controls the flow of information into the workspace from sensory and long-term memory systems. Working memory enables integration over time and across information sources, supporting thought and action control. The content of working memory is assumed to constitute the information about which we can be conscious, though not all information in working memory necessarily becomes conscious.

## Key facts

- Working memory consists of a temporary information storage system (the workspace) and a control system that performs executive functions. [raw/books/neuroscience/Anxious - Joseph LeDoux.pdf#p229]
- Attention is a key executive function that controls the flow of information into the workspace from sensory and long-term memory systems. [raw/books/neuroscience/Anxious - Joseph LeDoux.pdf#p229]
- The content of working memory is assumed to constitute the information about which we can be conscious. [raw/books/neuroscience/Anxious - Joseph LeDoux.pdf#p230]
- Working memory does not, on its own, completely account for conscious experience, as not all information in working memory necessarily becomes conscious. [raw/books/neuroscience/Anxious - Joseph LeDoux.pdf#p230]

## Inferences

- Inference: Working memory provides the cognitive infrastructure for many conscious experiences but is insufficient by itself to explain phenomenal consciousness.

## Uncertainties

- Uncertain: The exact neural implementation of working memory and its relation to consciousness requires further investigation.
