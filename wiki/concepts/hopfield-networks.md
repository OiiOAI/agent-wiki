# Hopfield Networks

## Summary

A neural network model developed by physicist John Hopfield that explains how memories can be stored as patterns of neural activations and retrieved through convergence to the closest stored pattern.

## Key facts

- John Hopfield, an American physicist at Princeton University, pioneered Hopfield networks as a model for how neural network activity can organize into stable configurations representing memories. [raw/books/neuroscience/The forgetting machine _ memory, perception, and the - Rodrigo Quian Quiroga; hoopla digital.pdf#p19]
- In Hopfield networks, different memories correspond to different configurations of firing and silent neurons in a network. [raw/books/neuroscience/The forgetting machine _ memory, perception, and the - Rodrigo Quian Quiroga; hoopla digital.pdf#p20]
- Memory retrieval works by the network starting from an initial state and converging to the closest stored memory through energy minimization. [raw/books/neuroscience/The forgetting machine _ memory, perception, and the - Rodrigo Quian Quiroga; hoopla digital.pdf#p21]

## Inferences

- Inference: Hopfield networks provide a computational framework for understanding how the physical activity of neurons relates to psychological memory processes, bridging neuroscience and psychology.
