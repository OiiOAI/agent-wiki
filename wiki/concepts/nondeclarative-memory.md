# Nondeclarative Memory

## Summary

Nondeclarative memory is long-term memory demonstrated through performance without conscious recollection of what was learned. Henry Molaison retained nondeclarative memory for motor skills, such as how to use a walker, despite his profound declarative memory loss. This type of memory includes motor learning, classical conditioning, perceptual learning, and priming. The existence of nondeclarative memory in Henry revealed that different memory systems operate independently in the brain, with different anatomical substrates.

## Inferences

- Inference: Motor skills and habits are learned by recruiting different memory circuits than those required for declarative memory.
- Inference: The brain houses at least two different kinds of long-term memory systems: one for nondeclarative knowledge (which Henry retained) and another for declarative knowledge (which he lacked).

## Uncertainties

- Uncertain: The exact neural circuits supporting each subtype of nondeclarative memory remain incompletely characterized.
