# Memory Updating

## Summary

Memory updating occurs when memories are retrieved and modified with new information from the present. Each time we revisit a past event in our minds, we bring current knowledge that can subtly or profoundly alter the memory content. This process explains false memories, eyewitness testimony errors, and the possibility of therapeutic memory modification.

## Key facts

- Accessing a memory is more like hitting 'play' and 'record' at the same time—each time we revisit the past, information from the present can alter the memory content. [raw/books/neuroscience/Why We Remember_ Unlocking Memory's Power - Charan Ranganath.pdf#p149]
- Every time we recall an experience, what we remember is suffused with the residue of the last time we remembered it, and over time memories can drift further from the initial event. [raw/books/neuroscience/Why We Remember_ Unlocking Memory's Power - Charan Ranganath.pdf#p149]
- When we remember, we do not passively replay the past but actively reconstruct it, making memories susceptible to distortion from current knowledge, suggestions, and imagination. [raw/books/neuroscience/Why We Remember_ Unlocking Memory's Power - Charan Ranganath.pdf#p149]
- The hippocampus is effective at catching the difference between past and present contexts and updates memories accordingly when they are recalled. [raw/books/neuroscience/Why We Remember_ Unlocking Memory's Power - Charan Ranganath.pdf#p152]
