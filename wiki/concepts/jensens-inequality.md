# Jensen's Inequality

## Summary

Jensen's Inequality is a mathematical property that describes how the function of an average differs from the average of a function. When a function is convex (antifragile), the average of the function exceeds the function of the average — producing a hidden convexity bias or 'edge.' When concave (fragile), the reverse occurs — the average of the function is less than the function of the average, producing a hidden concavity bias that requires being much better than random to offset.

## Key facts

- If a function is convex (antifragile), the average of the function of something is higher than the function of the average of something. [raw/books/strategy/Antifragile_ Things That Gain from Disorde - Taleb, Nassim Nicholas.pdf#p375]
- If a function is concave (fragile), the average of the function is less than the function of the average. [raw/books/strategy/Antifragile_ Things That Gain from Disorde - Taleb, Nassim Nicholas.pdf#p377]
- Using the squaring function (convex) with a die: function of average payoff equals 12.25, but average of square payoff equals 15.17 — a 24 percent hidden edge. [raw/books/strategy/Antifragile_ Things That Gain from Disorde - Taleb, Nassim Nicholas.pdf#p375]
- Someone with convex payoff (antifragile) can guess worse than random and still outperform — the more uncertainty, the better they do. [raw/books/strategy/Antifragile_ Things That Gain from Disorde - Taleb, Nassim Nicholas.pdf#p376]
- The hidden benefit of antifragility is that you can be wrong and still do well; the hidden harm of fragility is needing to be much better than random just to offset negative effects. [raw/books/strategy/Antifragile_ Things That Gain from Disorde - Taleb, Nassim Nicholas.pdf#p377]

## Inferences

- Inference: Jensen's Inequality explains why optionality (a convex payoff) is so powerful — it generates positive convexity bias that grows with uncertainty. This is why 'you can be dumb and antifragile and still do very well.'
- Inference: The grandmother example (0 degrees then 140 degrees averaging 70 degrees) illustrates concavity: the health function curves inward, making the average of extremes worse than the stable condition.
