# Learning and Memory

## Summary

Learning refers to behavioral changes resulting from acquiring knowledge about the world, while memory is the process by which knowledge is encoded, stored, and retrieved. Memory can be classified by time course (short-term/working memory versus long-term memory) and by nature of information stored. Long-term memory is divided into explicit (conscious/declarative) and implicit (nondeclarative) forms, with explicit memory further subdivided into episodic and semantic memory.

## Key facts

- Learning refers to a change in behavior that results from acquiring knowledge about the world, and memory is the process by which that knowledge is encoded, stored, and later retrieved. [raw/books/neuroscience/Principles of Neural Science, Fifth Edition (Principles of - Eric R_ Kandel; James H_ Schwartz; Thomas M_ Jessell; Steven.pdf#p1453]
- Working memory maintains transient representations of goal-relevant knowledge and consists of subsystems for verbal and visuospatial information coordinated by executive control processes. [raw/books/neuroscience/Principles of Neural Science, Fifth Edition (Principles of - Eric R_ Kandel; James H_ Schwartz; Thomas M_ Jessell; Steven.pdf#p1453]
- Long-term memory is classified as explicit (conscious/declarative) or implicit (nondeclarative), with explicit memory further divided into episodic and semantic forms. [raw/books/neuroscience/Principles of Neural Science, Fifth Edition (Principles of - Eric R_ Kandel; James H_ Schwartz; Thomas M_ Jessell; Steven.pdf#p1453]
- Patient H.M. demonstrated that bilateral medial temporal lobe lesions cause profound inability to form new long-term memories while preserving working memory and pre-surgery memories. [raw/books/neuroscience/Principles of Neural Science, Fifth Edition (Principles of - Eric R_ Kandel; James H_ Schwartz; Thomas M_ Jessell; Steven.pdf#p1494]
- Semantic memory is general knowledge about the world stored in distributed manner in the neocortex, including lateral and ventral temporal lobes.
