# Getting Things Done

## Summary

Getting Things Done (GTD) is a productivity methodology book by David Allen, first published in 2001 by Viking Penguin and subsequently revised in 2015 with a foreword by James Fallows. The book presents a comprehensive system for managing tasks and reducing stress through capturing, clarifying, organizing, reflecting, and engaging with work items.
