# 社会学的想象力

## Summary

《社会学的想象力》是美国社会学家C·赖特·米尔斯于1959年出版的经典社会学著作。该书批判了当时美国社会学界的抽象经验主义和宏大理论两种倾向，倡导一种将个人生活历程、历史和社会结构三者相结合的社会学研究视角。本书第八章专门论述历史在社会科学研究中的运用地位，强调社会科学本身即为历史学科，必须充分利用历史资料和历史视角。

## Key facts

- 社会科学探讨的是个人生活历程、历史和它们在社会结构中交织的问题. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p162]
- 如果不运用历史，不具备心理事件的历史感，社会科学家就不可能对现在应成为研究定位点的那些问题进行完整的表述. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p162]
- 所有名副其实的社会学都应该是'历史社会学'. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p165]
- 历史学的研究工作不只是使我们更加意识结构的存在；如果不运用历史资料，我们就别指望能理解任何一个单个的社会. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p168]
- 本书第十章讨论社会科学研究者的政治角色，作者认为社会科学研究有三种主要角色：哲学王、国王的幕僚、以及独立自主的研究者。. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p201]
- 作者指出社会科学的三个核心价值：事实原则、理性在人类事务中的角色、以及人类的自由。. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p201]
- 附录部分系统阐述了治学之道，包括学术档案的建立、研究设计、笔记方法、交叉分类技巧、以及写作风格的建议。. [raw/books/sociology/社会学的想象力 - 美 - c - 赖特 - 米尔斯.pdf#p212]
